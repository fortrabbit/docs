## About domain registration

A domain registrar sells domains, usually by the year. Once registered, point the domain to a fortrabbit environment with DNS records, see the [external domain setup](/1.platform/13.domains/04.external-domain-setup.md).

Domains come bundled with hosting packages or from dedicated providers, see [providers](/4.integrations/02.dns/02.providers.md). A local provider can be cheaper for the country TLD. Things to compare:

1. Advanced DNS configuration support
2. IMAP/POP3 e-mail accounts - see [email providers](/4.integrations/05.email/01.intro.md)
3. Exotic top-level domains (TLDs)
4. General domain forwarding with HTTPS
5. Support for domain forwards using [ALIAS or ANAME records](/4.integrations/02.dns/aname-alias-records.md)

Some providers bundle domains and e-mail, others offer only domains or only DNS.

## How does the domain provider relate to fortrabbit?

fortrabbit provides neither domain registration nor name servers. The domain points to fortrabbit with the records the dashboard shows, see [instructions per provider](/4.integrations/02.dns/04.instructions.md).

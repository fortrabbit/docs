[DDEV](https://ddev.com/) is a command line tool on top of Docker that sets up web server, PHP and database per project. It comes from the Drupal world and is common with [Craft CMS](/2.guides/3.craft-cms/01.install.md), [Symfony](/2.guides/7.more/08.symfony.md), [Laravel](/2.guides/2.laravel/01.install.md) and [WordPress](/2.guides/6.wordpress/01.setup.md). DDEV is open source under the Apache 2.0 license and funded by sponsors.

## Installation

DDEV runs on macOS, Linux and Windows and needs a Docker provider first: [Docker Desktop](https://www.docker.com/products/docker-desktop/) or, on macOS, [OrbStack](https://orbstack.dev/).

```bash
# Install DDEV with Homebrew (macOS)
brew install ddev/ddev/ddev

# One-time setup for local HTTPS
mkcert -install
```

For Windows and other methods, see the [DDEV installation docs](https://docs.ddev.com/en/stable/users/install/ddev-installation/).

## Usage

```bash
# Configure the project, from its root folder
ddev config

# Start the containers
ddev start

# Show URLs and database details
ddev describe

# Open the project in the browser
ddev launch

# Open a shell in the web container
ddev ssh
```

## SSH keys

To deploy or sync with fortrabbit from inside the container, make the local SSH keys available to it:

```bash
ddev auth ssh
```

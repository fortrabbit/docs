[Laravel Sail](https://laravel.com/docs/sail) runs a Laravel project in Docker containers, one isolated environment per project. It needs a Docker provider such as Docker Desktop.

## Installation

To add Sail to an existing project:

```bash
composer require laravel/sail --dev
php artisan sail:install
```

## Usage

```bash
# Start the containers
./vendor/bin/sail up

# Run Artisan commands
./vendor/bin/sail artisan migrate

# Run Composer
./vendor/bin/sail composer require guzzlehttp/guzzle
```

A [shell alias](https://laravel.com/docs/sail#configuring-a-shell-alias) shortens `./vendor/bin/sail` to `sail`.

## Sail, Valet and Herd

[Valet](/4.integrations/01.local-development/03.laravel-valet.md) and [Herd](/4.integrations/01.local-development/04.laravel-herd.md) run PHP on the host system. Sail runs everything in containers: nothing gets installed on the computer itself, but Docker uses more memory.

## Working with fortrabbit

Sail is for local development only. A deployment to fortrabbit sends the code, not the containers; the environment provides PHP and MySQL. Match the PHP version in `docker-compose.yml` to the [PHP version](/3.dev/20.how-to/upgrade-php.md) of the environment.

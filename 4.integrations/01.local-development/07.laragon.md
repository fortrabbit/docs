[Laragon](https://laragon.org/) runs its services without virtualization and installs into one self-contained folder. Composer and npm come bundled.

Without a license, Laragon is allowed for non-commercial use only and shows a license reminder. Commercial use needs a paid license, per year or with five years of updates.

## Installation

Download the installer from [laragon.org](https://laragon.org/) and run it. Laragon starts its services from a system tray app.

## Usage

1. Put the project into the `laragon/www/` folder.
2. Laragon creates a virtual host `projectname.test` for each subfolder.
3. Click **Start All** to start the web server, MySQL and PHP.
4. Open `http://projectname.test`.

## Working with fortrabbit

Use git and Composer from the Laragon terminal and deploy as usual, see [deployment](/1.platform/06.deployment/01.intro.md). Set up an [SSH key](/3.dev/15.learn/01.ssh-key-setup.md) for SSH and SFTP access to the environment.

[Laravel Herd](https://herd.laravel.com/) is made by the Laravel team. It works for Laravel and other PHP projects. Compared to [Laravel Valet](/4.integrations/01.local-development/03.laravel-valet.md) it needs no Homebrew or terminal setup, compared to [Laravel Sail](/4.integrations/01.local-development/05.laravel-sail.md) no Docker.

## Free and Pro

| | Free | Herd Pro |
| -- | -- | -- |
| PHP, NGINX, DNS, Node, Composer | ✓ | ✓ |
| MySQL, PostgreSQL, Redis | — | ✓ |
| Mail, Xdebug detection | — | ✓ |

With the free version, run MySQL separately, for example with [DBngin](https://dbngin.com/).

## Installation and usage

Download the installer from the website and run it. Herd sits in the menu bar or system tray and serves every folder in `~/Herd` as a `.test` domain:

1. Create `~/Herd/my-project`
2. Open `http://my-project.test`

Switch the PHP version globally or per site from the Herd menu.

## Working with fortrabbit

Herd uses the SSH keys in `~/.ssh`, so git pushes and SSH access to fortrabbit work with the keys set up there.

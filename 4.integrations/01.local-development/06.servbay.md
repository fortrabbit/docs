[ServBay](https://www.servbay.com/) runs on macOS and Windows. Besides PHP it covers Node.js, Python, Go and other runtimes, and databases from MySQL to Redis.

The free tier is limited to five websites. The paid Pro and Team plans remove the limit and add a mail server and backups.

## Installation

Download the installer, run it and start the app. ServBay manages all services from its interface.

## Usage

1. Create a new website in ServBay.
2. Pick the project folder and a local domain.
3. Select the PHP version for the project.
4. Start the web server and open the local URL.

## Database

Start a database service such as MySQL in ServBay, then connect the project with the host and port ServBay shows.

## Working with fortrabbit

ServBay runs on the host system and uses the SSH keys in `~/.ssh` for git and SSH access to fortrabbit.

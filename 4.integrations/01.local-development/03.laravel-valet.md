[Laravel Valet](https://laravel.com/docs/valet) runs PHP natively on macOS, without containers or virtual machines. It works for Laravel and most other PHP frameworks and CMS. Valet is open source under the MIT license.

## Installation

Valet needs [Homebrew](https://brew.sh/), PHP and Composer.

```bash
brew install php
composer global require laravel/valet
valet install
```

## Usage

```bash
# Serve every folder in ~/Sites as <folder>.test
cd ~/Sites
valet park

# Serve a single project folder as project.test
cd ~/path/to/project
valet link

# Serve a site over HTTPS
valet secure my-project

# Switch PHP globally, or for one site
valet use php@8.5
cd ~/Sites/legacy-project
valet isolate php@7.4
```

## Database

Valet includes no database. Install MySQL with Homebrew, `brew install mysql`, or use [DBngin](https://dbngin.com/).

## Working with fortrabbit

Valet runs on the host system and uses the local SSH keys in `~/.ssh` for git and SSH access to fortrabbit. [PHP Monitor](https://phpmon.app/) adds a menu bar interface for Valet.

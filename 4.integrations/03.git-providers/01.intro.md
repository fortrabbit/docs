## GitHub

fortrabbit integrates natively with GitHub through a dedicated [GitHub App](/1.platform/06.deployment/02.github-app.md), providing deep platform integration and the recommended deployment method.

## Other providers

GitLab, Bitbucket and Codeberg have no direct integration. A CI pipeline, such as GitLab CI, Bitbucket Pipelines or Forgejo Actions on Codeberg, builds the code and copies it to fortrabbit with [rsync](/3.dev/20.how-to/rsync.md) over SSH, authenticated with a [deploy key](/1.platform/10.objects/12.ssh-key.md#deploy-keys). The [GitHub Actions example](/4.integrations/03.git-providers/02.github.md#example-deploy-via-rsync) shows the steps.

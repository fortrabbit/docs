[FileZilla](https://filezilla-project.org/) is open source under the GPL.

::CallOut{alert}
The installer can offer optional third-party software. Decline it during setup.
::

## Setup

1. Open FileZilla and go to **File > Site Manager**.
2. Click **New Site**.
3. **Protocol**: Select `SFTP - SSH File Transfer Protocol`.
4. **Host**: `ssh.{{region}}.frbit.app`
5. **Port**: `22`
6. **Logon Type**: Select `Key file`.
7. **User**: `{{app-env-id}}`
8. **Key file**: Browse and select the private SSH key.
9. Click **Connect**.

FileZilla offers to convert an OpenSSH key to PuTTY's `.ppk` format when it is selected. Accept the conversion.

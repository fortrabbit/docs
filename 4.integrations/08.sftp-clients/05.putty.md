[PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/) handles SSH terminal sessions, PSFTP from the same suite transfers files over SFTP. PuTTY uses keys in its own `.ppk` format; PuTTYgen creates them or converts OpenSSH keys.

## OpenSSH on Windows

The OpenSSH client is an optional feature from Windows 10 version 1809 on. With it, the commands from the docs run in PowerShell as written:

```shell
ssh {{app-env-id}}@ssh.{{region}}.frbit.app
sftp {{app-env-id}}@ssh.{{region}}.frbit.app
```

See [SSH key setup](/3.dev/15.learn/01.ssh-key-setup.md) to create a key, and [OpenSSH for Windows](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_install_firstuse) to turn on the client.

## Graphical clients

For drag and drop on Windows, use [WinSCP](/4.integrations/08.sftp-clients/06.winscp.md) or [Cyberduck](/4.integrations/08.sftp-clients/02.cyberduck.md).

Code goes out with git. SFTP is for browsing files, downloading logs, uploading assets and troubleshooting. The connection details are on the [SFTP page](/1.platform/05.code-access/04.sftp.md).

## SFTP only

fortrabbit speaks SFTP, the SSH File Transfer Protocol. FTP and FTPS do not work. Every client listed here supports SFTP.

## SSH keys, no passwords

The login uses an [SSH key](/1.platform/10.objects/12.ssh-key.md); leave the password field empty. Set up a key with [SSH key setup](/3.dev/15.learn/01.ssh-key-setup.md).

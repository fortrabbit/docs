## About Blackfire

Blackfire records a profile of a request: time and memory per function, database queries and calls to other services. It also runs performance tests. Profiles from production show the real slow spots, and faster code can need a smaller [PHP plan](/1.platform/09.components/01.php.md).

## Pricing

Blackfire is billed by Blackfire, not by fortrabbit. See [Blackfire pricing](https://www.blackfire.io/pricing).

## Integration

Three steps:

### Over at Blackfire

- Log in to [Blackfire](https://blackfire.io).
- Open the [server credentials](https://blackfire.io/my/settings/credentials).
- Copy the Server ID and the Server Token.

### At fortrabbit

- Open the [PHP settings](/1.platform/07.settings/06.php.md) of the environment in the dashboard.
- Switch on the Blackfire extension.
- Paste the Server ID and the Server Token, and save.
- Wait a minute until PHP restarts with the extension.

### In your browser

- Install the Blackfire extension for [Chrome](https://blackfire.io/docs/integrations/chrome) or [Firefox](https://blackfire.io/docs/integrations/browsers/firefox).
- Open the website and click the Blackfire button to profile the page.

## Limitations

Command line scripts, such as jobs, need the [Blackfire PHP SDK](https://blackfire.io/docs/integrations/php/sdk) to be profiled.

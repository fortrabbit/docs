## About New Relic

[New Relic](https://newrelic.com) records all requests of an app and shows slow transactions, errors and queries over time. Its PHP extension is installed on fortrabbit and switched off by default.

## Pricing

New Relic bills its own account, with a free tier, see [New Relic pricing](https://newrelic.com/pricing).

## Usage

Connect with the license key of a New Relic account.

### Over at New Relic

1. Log in to [New Relic](https://newrelic.com).
2. Open the API keys page and copy the license key, see [New Relic API keys](https://docs.newrelic.com/docs/apis/intro-apis/new-relic-api-keys/). The New Relic interface changes often, the docs page stays current.

There is nothing to install on fortrabbit.

### At fortrabbit

1. Open the [PHP settings](/1.platform/07.settings/06.php.md) of the environment in the dashboard.
2. Switch on the New Relic extension and paste the license key.
3. Save.

Data shows up in New Relic a few minutes later, see the [New Relic APM docs](https://docs.newrelic.com/docs/apm/new-relic-apm/getting-started/introduction-new-relic-apm).

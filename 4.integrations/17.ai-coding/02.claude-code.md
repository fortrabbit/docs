[Claude Code](https://claude.com/claude-code) was released by Anthropic in 2025. Start it in the project folder, describe a task in plain language, and it reads files, writes changes and runs shell commands until the task is done.

## Agentic capabilities

It refactors a module, traces a bug from an error message to its source, writes and runs tests, or explains an unfamiliar codebase. Permission settings decide which edits and commands need a confirmation.

## Editor integration

Besides the terminal, Claude Code runs as an extension in [VS Code](/4.integrations/16.code-editors/02.vscode.md) and JetBrains IDEs such as [PhpStorm](/4.integrations/16.code-editors/03.phpstorm.md), with diffs to accept or reject in the editor.

## Pricing

Claude Code comes with the paid Claude plans, Pro, Max, Team and Enterprise, or bills per token through the Anthropic API. There is no free tier.

## Privacy

Code context is processed on Anthropic's servers. See [Anthropic's privacy policy](https://www.anthropic.com/legal/privacy) for how data from consumer plans and the API is handled.

## Integration with fortrabbit

The [MCP server](/1.platform/04.automation/02.mcp.md) connects with one command. It registers fortrabbit for every directory instead of the current project, which fits objects that belong to an account rather than to a repository. Authorization follows on the first connection, in the browser:

:BlockLink{title="MCP setup for Claude Code" path="/mcp?client=claude-code" property="www"}

The [agent skills](/1.platform/04.automation/04.agent-skills.md) install into `~/.claude/skills` and carry what MCP does not: deployments, SSH commands, database sync, guided environment setup. The [frbit CLI](/1.platform/04.automation/03.cli.md) sets up both in one step with `frbit setup agent`.

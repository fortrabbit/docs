[GitHub Copilot](https://github.com/features/copilot) launched in 2021. It is built into VS Code and available as an extension for JetBrains IDEs, Neovim, Xcode and other editors.

## Features

Copilot completes code while typing, answers and edits in a chat panel, and in agent mode works through tasks across files and runs terminal commands. It is most complete in VS Code.

## Model selection

Copilot runs models from OpenAI, Anthropic and Google, picked per chat. Which models are available depends on the plan.

## Pricing

Copilot Free has a monthly limit on completions and chat requests. Paid plans for individuals, business and enterprise raise the limits and add admin controls. Verified students and teachers get it for free.

## Privacy

Code context goes to GitHub for processing. GitHub does not train models on Copilot Business and Enterprise data; individual accounts control data use in their Copilot settings, where suggestions matching public code can be blocked too.

## Integration with fortrabbit

The [agent skills](/1.platform/04.automation/04.agent-skills.md) reach Copilot per project only, as a repository-scoped instructions file. A project install writes `.github/instructions/fortrabbit.instructions.md`, and there is no global equivalent — the skill files themselves are read by Claude Code and Codex.

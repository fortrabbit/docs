[Codex](https://openai.com/codex) is OpenAI's coding agent, released in 2025. It shares the name with the earlier Codex model behind the first GitHub Copilot, retired in 2023.

## Terminal, editor and cloud

The CLI works interactively against the local checkout, and an extension brings the same agent into VS Code and its forks. Codex cloud takes a fully described task, clones the repository into a sandbox, runs commands, edits files and returns a pull request. Cloud tasks run in parallel and report back when done.

## Access

Codex comes with the paid ChatGPT plans and is also reachable through the OpenAI API. Usage limits depend on the tier. The CLI, the editor extension and the cloud share one account.

## Privacy

Cloud tasks run on OpenAI's infrastructure, and the CLI sends code context there. See [OpenAI's usage policies](https://openai.com/policies/usage-policies) before using Codex on sensitive code.

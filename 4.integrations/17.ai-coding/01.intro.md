## Assistants and editor AI

The AI built into editors such as [VS Code](/4.integrations/16.code-editors/02.vscode.md), [Zed](/4.integrations/16.code-editors/05.zed.md) and [Cursor](/4.integrations/16.code-editors/04.cursor.md) completes lines, answers in a chat panel and rewrites a selection. Coding assistants work as agents: they read the whole codebase, edit several files, run shell commands and test until a task is done. The line blurs, since Copilot and Windsurf started as autocomplete and added agents.

## What to compare

| Criterion | Question |
| -- | -- |
| Model | Which models it runs, and whether you can switch |
| Autonomy | Suggestions only, or edits, commands and test runs on its own |
| Interface | Terminal, editor extension, own IDE or cloud |
| Privacy | What code context leaves the computer, local model support |
| Price | Free quota, subscription or pay per token |

## Integration with fortrabbit

An assistant reads the repository, but not the hosting account: which environment runs which PHP version, or why the last deployment failed. Three pieces connect it to fortrabbit.

**[MCP server](/1.platform/04.automation/02.mcp.md)** — a live connection to the account. The agent lists apps and environments, reads the build output of a failed deployment, clones an environment or sets a variable. Authorization runs in the browser, so no token is pasted into a config file. Setup is one command per client:

:BlockLink{title="MCP setup instructions" path="/mcp" property="www"}

**[Agent skills](/1.platform/04.automation/04.agent-skills.md)** — the workflow knowledge MCP does not carry: how a deployment is done, how a database is synced, which command to run over SSH. Installed once, they stop an agent from guessing at platform conventions.

**[CLI](/1.platform/04.automation/03.cli.md) and [public API](/1.platform/04.automation/05.api.md)** — the fallback for anything the tool set does not expose. An assistant that can run shell commands can run `frbit`, and the API covers the rest.

Support differs per assistant. The pages below note what each one connects to.

## Assistants compared

| Assistant | Runs in | fortrabbit MCP | Agent skills |
| -- | -- | -- | -- |
| [Claude Code](/4.integrations/17.ai-coding/02.claude-code.md) | Terminal, VS Code, JetBrains | One command | Yes |
| [GitHub Copilot](/4.integrations/17.ai-coding/03.github-copilot.md) | VS Code, JetBrains and more | Through the editor | Per project |
| [Codex](/4.integrations/17.ai-coding/04.codex.md) | Terminal, VS Code, cloud | One command | Yes |

[MySQL Workbench](https://www.mysql.com/products/workbench/) covers data modeling, SQL development and server administration.

## Connection setup

Workbench reaches the database through an SSH tunnel to the environment.

1. Open MySQL Workbench and click the **+** icon to add a new connection.
2. **Connection Name**: Give it a name (for example `My App`).
3. **Connection Method**: Select `Standard TCP/IP over SSH`.
4. **SSH Hostname**: `ssh.{{region}}.frbit.app`
5. **SSH Username**: `{{app-env-id}}`
6. **SSH Key File**: Browse and select your local private SSH key (for example `~/.ssh/id_ed25519`).
7. **MySQL Hostname**: `mysql` (Do not use localhost or an IP address).
8. **MySQL Server Port**: `3306`
9. **Username**: `{{app-env-id}}`
10. **Password**: Click **Store in Keychain** and enter the database password from the dashboard.
11. **Default Schema**: `{{app-env-id}}`

Click **Test Connection**, then **OK** to save. When the connection fails, see [MySQL troubleshooting](/1.platform/08.mysql/19.troubleshooting.md).

[Sequel Ace](https://sequel-ace.com/) is a fast, open-source, native MySQL/MariaDB client for macOS and the successor to Sequel Pro. It's free to use.

## Connection setup

To connect to the fortrabbit database, use the **SSH** connection tab. SSH tunneling is required for secure remote access.

1. Open Sequel Ace and select the **SSH** tab.
2. **Name**: Give it a name (e.g., `My App`).
3. **MySQL Host**: `mysql` (Do not use localhost or an IP address).
4. **Username**: `{{app-env-id}}`
5. **Password**: Enter the database password from the Dashboard.
6. **Database**: `{{app-env-id}}`
7. **Port**: `3306`
8. **SSH Host**: `ssh.{{region}}.frbit.app`
9. **SSH User**: `{{app-env-id}}`
10. **SSH Key**: Select your local private SSH key (e.g., `~/.ssh/id_rsa`).
11. **Get Public Key**: Tick the checkbox (Sequel Ace 5.3.0 or later).

Click **Test Connection** to verify, then **Connect** or **Add to Favorites**.

## Troubleshooting

`Authentication plugin 'caching_sha2_password' reported error: Authentication requires secure connection.`

Sequel Ace connects without TLS by default. MySQL 8 accepts that only for a user whose login is still cached on the server. A new environment, or any environment after a MySQL restart, has no cached login yet. Tick **Get Public Key** so the password is exchanged with the server's RSA key. The SSH tunnel encrypts the connection. Leave **Enable Cleartext plugin** off.

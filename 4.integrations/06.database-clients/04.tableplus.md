[TablePlus](https://tableplus.com/) connects to MySQL, PostgreSQL, SQLite, Redis and other engines. The free trial limits the app to two open tabs and two windows; a license is a one-time purchase with one year of updates.

## Connection setup

The database of an environment is reachable only through an SSH tunnel, set up with the **Over SSH** option.

1. Open TablePlus and create a new connection.
2. Select **MySQL** as the driver.
3. **Name**: Give it a name (for example `My App`).
4. **Host**: `mysql` (Do not use localhost or an IP address).
5. **Port**: `3306`
6. **User**: `{{app-env-id}}`
7. **Password**: Enter the database password from the dashboard.
8. **Database**: `{{app-env-id}}`
9. Enable **Over SSH**.
10. **Server**: `ssh.{{region}}.frbit.app`
11. **Port**: `22`
12. **User**: `{{app-env-id}}`
13. **Use SSH Key**: Select your local private SSH key.

Click **Test** to verify the connection, then **Save**.

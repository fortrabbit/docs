[TablePro](https://tablepro.app/) is open source under the AGPL. It connects to MySQL, MariaDB, PostgreSQL, SQLite, MongoDB, Redis and more than 30 other engines. Paid plans add schema compare and sync, and team features. An optional AI assistant works with Claude, OpenAI, GitHub Copilot, a local Ollama model and other providers. Install it with `brew install --cask tablepro` or from the website.

## Connection setup

The database of an environment is reachable only through an SSH tunnel, authenticated with the local SSH key.

1. Open TablePro and create a new connection.
2. Select **MySQL** as the driver.
3. **Name**: Give it a name (for example `My App`).
4. **Host**: `mysql` (Do not use localhost or an IP address).
5. **Port**: `3306`
6. **Username**: `{{app-env-id}}`
7. **Password**: Enter your database password from the dashboard.
8. **Database**: `{{app-env-id}}`
9. Toggle **SSH Tunnel** on.
10. **SSH Host**: `ssh.{{region}}.frbit.app`
11. **SSH Port**: `22`
12. **SSH User**: `{{app-env-id}}`
13. **Authentication**: select **Private Key**.
14. **Key File**: browse to your local private SSH key (for example `~/.ssh/id_ed25519`).

Click **Test Connection** to verify, then **Create** to save.

## Why a native client

A desktop database client connects through an SSH tunnel with the same key used for SSH and SFTP, so credentials and data travel encrypted. It handles large result sets and imports better than a browser tab and keeps local and remote databases side by side.

See [MySQL access with a GUI](/1.platform/08.mysql/01.access/03.access-local-gui.md) for the connection details.

Sequel Ace and MySQL Workbench cover a single MySQL database well. DBeaver, DataGrip, TablePlus and TablePro also connect to PostgreSQL, SQLite, Redis and other engines, which helps when a project uses an [external database](/4.integrations/09.database-hosting/01.intro.md) next to the [MySQL component](/1.platform/09.components/02.mysql.md).

## AI features

Some clients write SQL from a prompt or explain queries: DataGrip with the JetBrains AI Assistant, and TablePro with Claude, OpenAI, GitHub Copilot, a local Ollama model and other providers.

::CallOut
Read AI-generated SQL before running it, try it on a local database first, and never run it against a production environment without a review.
::

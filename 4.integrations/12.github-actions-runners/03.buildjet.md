[BuildJet](https://buildjet.com/for-github-actions) has shut down its GitHub Actions runners. Workflows with `runs-on: buildjet-…` labels need a new runner.

Managed providers with ARM runners and a label switch: [Namespace](/4.integrations/12.github-actions-runners/02.namespace.md), [WarpBuild](/4.integrations/12.github-actions-runners/05.warpbuild.md), [Ubicloud](/4.integrations/12.github-actions-runners/07.ubicloud.md) and [Depot](/4.integrations/12.github-actions-runners/10.depot.md). Or let GitHub host the runners again.

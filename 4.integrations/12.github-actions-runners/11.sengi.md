[Sengi](https://sengi.run/) runs GitHub Actions jobs on managed Linux VMs, switched on with a `runs-on` label such as `sengi-basic-2-ubuntu-2404`. Basic costs $0.001, $0.002 and $0.004 a minute at 2, 4 and 8 vCPU, and every account gets 3,000 free Basic minutes a month. The Premium class is for jobs where build time matters. Workflows, secrets and logs stay in GitHub.

## Deploy to fortrabbit

The runner builds and tests. The deployment step connects over SSH with a [deploy key](/1.platform/10.objects/12.ssh-key.md#deploy-keys), see [GitHub Actions runners](/4.integrations/12.github-actions-runners/01.intro.md).

## Editors compared

| Editor | Price | Built on | AI |
| -- | -- | -- | -- |
| [VS Code](/4.integrations/16.code-editors/02.vscode.md) | Free, open source | Electron | GitHub Copilot, extensions |
| [PhpStorm](/4.integrations/16.code-editors/03.phpstorm.md) | Subscription, 30-day trial | JVM | JetBrains AI, free quota |
| [Cursor](/4.integrations/16.code-editors/04.cursor.md) | Free, paid AI tiers | VS Code fork | Built in, several providers |
| [Zed](/4.integrations/16.code-editors/05.zed.md) | Free, open source | Native, Rust | Built in, several providers, local models |

## Speed

Electron editors such as VS Code and Cursor embed a browser engine. They are easy to extend, but use more memory and start slower than native editors such as Zed or Sublime Text. JVM IDEs such as PhpStorm index the project at startup and are fast afterwards.

## PHP tooling

PhpStorm ships refactoring, static analysis, a database client, a test runner and Xdebug support. Free editors cover most of that with extensions.

## Privacy

AI features send code context to the model provider. Editors that support local models, through Ollama for example, keep code on the computer. Usage statistics can be turned off in each editor.

## Integration with fortrabbit

No plugin needed. Write and test code locally, commit and push; fortrabbit [deploys](/1.platform/06.deployment/01.intro.md) from GitHub. For a quick look at the files of an environment, use [SFTP](/1.platform/05.code-access/04.sftp.md) or [SSH](/1.platform/05.code-access/03.ssh.md). AI editors with MCP support can query apps, environments and deployment logs through the [MCP server](/1.platform/04.automation/02.mcp.md).

## Other editors

- **Sublime Text**: native and fast, one-time license, AI through plugins
- **Vim**: in the terminal on almost every Unix system, also over SSH on a fortrabbit environment

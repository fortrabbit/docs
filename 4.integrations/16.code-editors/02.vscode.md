[Visual Studio Code](https://code.visualstudio.com) is free. Its source is open source; [VSCodium](https://vscodium.com) is a build of it without Microsoft telemetry.

## Extensions

The marketplace covers PHP language support, Xdebug, formatting, git tooling, Docker and database clients. Most extensions are free.

## Performance

VS Code is an Electron app with an embedded browser engine. It uses more memory and starts slower than a native editor, most noticeable on older computers.

## AI

GitHub Copilot is built into VS Code and needs a GitHub Copilot plan for more than the free quota. [Claude Code](/4.integrations/17.ai-coding/02.claude-code.md) and other agents run as extensions.

## Privacy

VS Code sends usage data and crash reports to Microsoft by default; turn it off in the telemetry settings. Copilot sends code context to GitHub while it is active.

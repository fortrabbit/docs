[Cursor](https://cursor.com) is made by Anysphere. The editor is free to download; paid plans raise the AI usage limits. Moving over from [VS Code](/4.integrations/16.code-editors/02.vscode.md) takes the extensions and settings along.

## AI

Cursor has multi-line autocomplete, inline edits, a chat that sees the whole codebase and an agent that works across files. Models from several providers can be picked per feature.

## Performance

Like VS Code, Cursor is an Electron app and heavier than a native editor. AI completions add latency that depends on the model and the network.

## Privacy

AI features send code context to Cursor and the model provider. In privacy mode, code is not stored or used for training. See [Cursor's privacy policy](https://cursor.com/privacy).

[Zed](https://zed.dev) comes from some of the original authors of Atom and Tree-sitter. Some features of VS Code or PhpStorm are still missing.

## Performance

Zed is a native app that renders on the GPU, without Electron or a JVM. It starts almost instantly and stays fast with large files.

## AI

The AI panel and agent work with Anthropic, OpenAI, GitHub Copilot and local models through Ollama, among other providers.

## Privacy

Telemetry can be turned off in `~/.config/zed/settings.json`. Cloud AI providers receive code context; a local model through Ollama keeps it on the computer.

[Neon](https://neon.com/) runs open source Postgres with separate storage and compute, branching and autoscaling.

## PHP and Postgres

fortrabbit offers MySQL, not Postgres, but PHP connects to an external Postgres: the `pgsql` and `pdo_pgsql` extensions are always on.

### Laravel example

Laravel supports Postgres. Set the connection in the [ENV vars](/1.platform/07.settings/01.env-vars.md):

```bash
DB_CONNECTION=pgsql
DB_HOST=ep-random-name-123456.eu-central-1.aws.neon.tech
DB_PORT=5432
DB_DATABASE=neondb
DB_USERNAME=user
DB_PASSWORD=password
```

## Region

Neon runs on AWS. Create the database in the AWS region of the app, see [database hosting](/4.integrations/09.database-hosting/01.intro.md#latency-considerations).

[CrateDB](https://cratedb.com/) is a distributed SQL database built on a NoSQL foundation that makes it easy to store and analyze massive amounts of data in real-time. CrateDB uses the PostgreSQL wire protocol, so you can use many standard PostgreSQL clients and libraries to interact with it.

## Use cases

CrateDB usually runs next to a main database, such as the MySQL of fortrabbit: it takes the high-volume data and the analytical queries, MySQL the transactions.

## PHP integration

Connect with `pdo_pgsql`, which is always on, and store the credentials as [ENV vars](/1.platform/07.settings/01.env-vars.md). Port 5432 is open in the [outgoing firewall](/1.platform/07.settings/21.firewall-outgoing.md):

```php
$dsn = 'pgsql:host=crate-cluster.example.com;port=5432;user=crate;password=';
$pdo = new PDO($dsn);
```

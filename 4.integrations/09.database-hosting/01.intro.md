The app stays on fortrabbit, the database runs elsewhere, and the [MySQL component](/1.platform/09.components/02.mysql.md) stays off.

## Use cases

- Another database type, such as Postgres
- Very large databases
- Access from other places, with read-only users
- More detailed database statistics

## Connecting to external databases

1. Create the database with the provider.
2. Copy the host, user, password and database name.
3. Store them as [ENV vars](/1.platform/07.settings/01.env-vars.md) of the environment.

The MySQL port 3306 and the Postgres port 5432 are open in the [outgoing firewall](/1.platform/07.settings/21.firewall-outgoing.md). Open other ports there.

## Latency considerations

Every query travels to the database and back. Create the database in the AWS region of the app: `eu-west-1` (Ireland) for EU apps, `us-east-1` (Virginia) for US apps. The [app](/1.platform/10.objects/01.app.md) shows its region.

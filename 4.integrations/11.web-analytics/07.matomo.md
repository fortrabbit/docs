## About Matomo

[Matomo](https://matomo.org) is open source web analytics in PHP and MySQL. The data stays on the own server. Matomo can run without cookies.

## Pricing

Self-hosted Matomo is free, some plugins cost extra. [Matomo Cloud](https://matomo.org/pricing/) is the hosted version.

## Matomo on fortrabbit

Install Matomo as an [app](/1.platform/10.objects/01.app.md) of its own, with the [MySQL component](/1.platform/09.components/02.mysql.md). Matomo processes its reports in a cron job: add `php console core:archive` as a [cron](/1.platform/30.jobs/02.crons.md), for example every hour, see [Matomo report archiving](https://matomo.org/faq/on-premise/how-to-set-up-auto-archiving-of-your-reports/).

[Tower](https://www.git-tower.com/) covers everyday git work and the harder parts: interactive rebase, multiple remotes, merge conflicts and undo. Students and teachers can use it for free.

## Use it with fortrabbit

Clone the GitHub repository connected to the environment, commit and push. The [GitHub app](/1.platform/06.deployment/02.github-app.md) deploys the push.

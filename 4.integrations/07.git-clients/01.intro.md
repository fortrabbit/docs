New to git? Start with the [git intro](/3.dev/15.learn/git-intro.md).

## Terminal, client or editor

| Where | Good for |
| -- | -- |
| Terminal | Scripts, quick commits, every command |
| Desktop client | Reviewing diffs, resolving merge conflicts, browsing history, squashing commits |
| Code editor | Staging and committing while coding |

## Desktop clients

- [GitHub CLI](/4.integrations/07.git-clients/02.gh-cli.md): GitHub pull requests and issues in the terminal
- [Fork](/4.integrations/07.git-clients/03.fork.md): macOS and Windows, one-time license
- [Tower](/4.integrations/07.git-clients/04.tower.md): macOS and Windows, yearly subscription
- [GitHub Desktop](/4.integrations/07.git-clients/05.github-desktop.md): macOS and Windows, free and open source

## Code editors

VS Code has a Source Control view for staging changes and resolving merge conflicts inline. PhpStorm has a full git client built in, and its Local History keeps changes that were never committed. See [code editors](/4.integrations/16.code-editors/01.intro.md).

## Git and fortrabbit

fortrabbit hosts no git repositories. The code lives with a [git provider](/4.integrations/03.git-providers/01.intro.md). The [fortrabbit GitHub app](/1.platform/06.deployment/02.github-app.md) deploys every push to GitHub, other providers deploy through a CI pipeline.

[Fork](https://git-fork.com/) shows branches, diffs and history side by side and handles interactive rebase, merge conflicts, stashes and submodules. It works well next to git in the terminal or in the code editor.

## Use it with fortrabbit

Clone the GitHub repository connected to the environment, commit and push. The [GitHub app](/1.platform/06.deployment/02.github-app.md) deploys the push.

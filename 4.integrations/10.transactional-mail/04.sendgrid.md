## About SendGrid

[SendGrid](https://sendgrid.com), owned by Twilio since 2019, sends transactional and marketing e-mail by API or SMTP.

## Pricing

SendGrid has paid plans and checks new accounts before they can send, see [SendGrid pricing](https://sendgrid.com/en-us/pricing).

## Set up

Verify the domain with the DKIM and SPF records SendGrid shows, at the [DNS provider](/4.integrations/02.dns/02.providers.md) of the domain.

## Using SendGrid with fortrabbit

Install the [SendGrid PHP library](https://github.com/sendgrid/sendgrid-php):

```shell
composer require sendgrid/sendgrid
```

Store the SendGrid API key as an [ENV var](/1.platform/07.settings/01.env-vars.md) and pass it to the client. Frameworks can also send through the SMTP access of SendGrid with the API key as password.

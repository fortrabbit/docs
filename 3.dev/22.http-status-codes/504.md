## How a 504 shows

- The page loads for a long time before the error appears.
- The errors come and go, often with traffic peaks or after an editor's action in a CMS.
- They appear without a deployment. See [performance problems are often people problems](/3.dev/02.performance/02.people-problems.md).
- The PHP log stays empty: a request that times out ends before it can write an error.

## Find the slow requests

The [metrics](/1.platform/07.settings/30.metrics.md) of the environment show the PHP response time and the HTTP errors per hour. A 504 spike sits on top of a rising response time. The access log in the [logs](/1.platform/07.settings/25.logs.md) shows which paths were requested at that time; paths that repeat often are the first suspects.

## Common causes

| Cause | Read |
| -- | -- |
| Slow or too many database queries | [Database performance](/3.dev/02.performance/08.database.md) |
| Image transforms on upload or first view | [Craft CMS image transforms](/2.guides/3.craft-cms/16.image-transforms.md) |
| An external API that answers late | Set a short timeout in the HTTP client |
| Bots crawling endless filter or search URLs | [Block IPs](/3.dev/21.htaccess/08.block-ip.md), [incoming firewall](/1.platform/07.settings/20.firewall-incoming.md) |
| Plugins, loops, templates that include themselves | [Common issues](/3.dev/02.performance/03.common-issues.md) |

A profiler such as [Blackfire](/4.integrations/04.apm/02.blackfire.md) shows where a slow request spends its time. Full-page caching, in the app or in a CDN such as [Cloudflare](/4.integrations/02.dns/05.cloudflare.md), takes most requests off PHP.

## Timeouts

`max_execution_time` in the [PHP settings](/1.platform/07.settings/06.php.md) ends a PHP script after the set number of seconds. A low value frees the PHP process sooner, so one slow request blocks fewer others. See [PHP processes](/3.dev/02.performance/06.php-processes.md).

## Platform status

When the metrics show no slow requests, check the [fortrabbit status page](https://fortrabbit.betteruptime.com/) for incidents.

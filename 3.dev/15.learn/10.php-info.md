## Show phpinfo

`phpinfo()` prints the PHP version, the loaded extensions with their versions, all ini settings and the environment variables of the running PHP.

1. Create a file `info.php` in the root path, `web` or `public` depending on the software.
2. Put this line in it:

   ```php
   <?php phpinfo();
   ```

3. Open `https://example.com/info.php` in the browser.
4. Delete the file when done.

To see only one part, pass a constant, such as `phpinfo(INFO_MODULES)` for the extensions. See [phpinfo on php.net](https://www.php.net/manual/en/function.phpinfo.php).

## phpinfo in the terminal

Over [SSH](/1.platform/05.code-access/03.ssh.md), `php -i` prints the same data as text. It shows the command line settings, which can differ from the settings of web requests. For a single value, use `php -r 'echo ini_get("memory_limit");'`.

## phpinfo in a CMS

Craft CMS shows it in the control panel under **Utilities → PHP Info**. WordPress shows server details under **Tools → Site Health → Info**.

## Keep phpinfo private

phpinfo shows every ENV var, including the database password and API keys. Never leave an `info.php` file on a public site. Bots request `info.php` and `phpinfo.php` on every domain. Delete the file right after use, or put the environment behind [password protection](/1.platform/07.settings/03.password-protection.md) while it exists. See [ENV var security](/3.dev/19.env-vars/20.security.md).

Change PHP settings in the [PHP settings](/1.platform/07.settings/06.php.md) of the environment.

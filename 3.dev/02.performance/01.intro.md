## No silver bullets

A powerful server alone does not make a website fast.

More hosting power helps when the code is efficient and the load is real. For a slow query or a page that loads too much, it buys little. The web developer has the biggest lever on performance.

:ContentQuote{text="Throwing more money at a hosting problem will rarely fix it."}

## Not all websites are alike

For some websites or individual pages, an execution time of 500 ms is acceptable, for others it is not. fortrabbit runs a wide range of different applications using software systems such as [Laravel](/2.guides/2.laravel/01.install.md), [Symfony](/2.guides/7.more/08.symfony.md), [Craft CMS](/2.guides/3.craft-cms/01.install.md), [WordPress](/2.guides/6.wordpress/01.setup.md) and many more.

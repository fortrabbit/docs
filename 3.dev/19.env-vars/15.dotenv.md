## The .env file

A `.env` file is a plain text file at the project root with one `KEY=value` pair per line. PHP does not read it by itself, a parser library loads it:

- [vlucas/phpdotenv](https://github.com/vlucas/phpdotenv), used by Laravel and Craft CMS
- [symfony/dotenv](https://github.com/symfony/dotenv), used by Symfony

[Laravel](/2.guides/2.laravel/01.install.md), [Symfony](/2.guides/7.more/08.symfony.md) and [Craft CMS](/2.guides/3.craft-cms/01.install.md) ship with a parser and a `.env` file.

## Keep .env files off the server

Set ENV vars on fortrabbit in the [dashboard](/1.platform/07.settings/01.env-vars.md). A `.env` file on the server adds a second source of configuration: depending on the parser, its values override the dashboard values or the other way round. Pick one, the dashboard is the recommended one.

Keep secrets out of git. Laravel and Craft CMS list `.env` in their `.gitignore`. Symfony commits `.env` with defaults and ignores `.env.local`, which holds the local secrets. See [ENV var security](/3.dev/19.env-vars/20.security.md).

## Use the costs overview

In the dashboard, under each of your [payment methods](/1.platform/10.objects/09.payment-method.md), you'll find an invoice archive and a draft invoice for the current month's costs. The [pro-rated daily billing](/1.platform/12.billing/02.postpaid.md) lets you remove unnecessary [components](/1.platform/03.concepts/03.components.md) with immediate effect.

## Review apps and environments

Look for [apps](/1.platform/10.objects/01.app.md) and [environments](/1.platform/10.objects/02.environment.md) nobody uses, such as an old side project or a finished staging setup. [Download](/3.dev/20.how-to/download-a-website.md) a complete copy, then delete them. The copy can be deployed again later.

## Check component plans

Compare the booked [components](/1.platform/03.concepts/03.components.md) with the [metrics](/1.platform/26.metrics/index.md). Try a smaller PHP or MySQL plan and watch response times and errors for a few days.

## Refactor code

Code that does less per request needs smaller plans. See the [performance section](/3.dev/02.performance/index.md) for optimization strategies.

When you log in with [SFTP](/1.platform/05.code-access/04.sftp.md) or [SSH](/1.platform/05.code-access/03.ssh.md) to your [environment](/1.platform/10.objects/02.environment.md), you can see the directory structure. This is what you'll find:

```raw
data
  www
  home
```

## www

The `www` folder holds the code and is the login folder, the starting point for SSH and SFTP. [Git deployment](/1.platform/06.deployment/01.intro.md) syncs to it as well. Without a framework or CMS, `www` itself is the web root (aka document root). Set the [root path](/1.platform/07.settings/12.root-path.md) to any folder below it.

- `/data/www`

## home

Like `~` on a local machine. Contains the bash history.

- `/data/home`

## Users and permissions

SSH, SFTP and PHP web requests all run as the same user, `app`. Strict modes such as `700` for directories and `600` for files keep the files private and PHP can still read them. Store private files outside the [root path](/1.platform/07.settings/12.root-path.md) so they are never served over HTTP.

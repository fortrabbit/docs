Direct code access fits software that does not deploy well with Git, quick checks, and content that stays out of Git, such as uploads. It works alongside [Git deployment](/1.platform/06.deployment/01.intro.md).

## SSH

SSH (Secure Shell) opens an interactive terminal session on the [environment](/1.platform/10.objects/02.environment.md), to run Composer, artisan or other commands. The `ssh` client comes with macOS, Linux and Windows.

See the [SSH guide](/1.platform/05.code-access/03.ssh.md).

## SFTP

SFTP (SSH File Transfer Protocol) transfers files over an SSH connection, usually with a graphical client. For repeated transfers, [rsync](/3.dev/20.how-to/rsync.md) over SSH is faster.

See the [SFTP guide](/1.platform/05.code-access/04.sftp.md).

## SSH key authentication

Both need an SSH key; passwords are not accepted. Upload the public key to the personal account in the dashboard, see [SSH key setup](/3.dev/15.learn/01.ssh-key-setup.md).

:BlockLink{title="Your SSH keys" path="/you/ssh-keys"}

The key belongs to the person, not to an environment. It works on every environment the account can access, and [adding or removing collaborators](/1.platform/20.collaboration/1.intro.md) updates code access with it.

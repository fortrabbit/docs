## Use cases

SFTP gets code onto a server, but for deployment, [Git](/1.platform/06.deployment/01.intro.md) or [rsync](/3.dev/20.how-to/rsync.md) are repeatable and safer. SFTP fits these tasks:

- **Browse files**: check what is on the environment.
- **Read log files**: log files the software writes itself, see [logs](/1.platform/07.settings/25.logs.md).
- **Upload assets**: large files that do not belong in Git.
- **Inspect**: look at generated files or make a quick fix.

## SFTP access details

```raw
Host:       ssh.{{region}}.frbit.app
User name:  {{app-env-id}}
Password:   none, the SSH key is used
Protocol:   SFTP (not FTP)
Port:       22
```

## SFTP clients

See the [SFTP clients](/4.integrations/08.sftp-clients/01.intro.md) for setup guides per client.

## SFTP is not FTP

SFTP is the SSH File Transfer Protocol and runs over an encrypted SSH connection. Despite the name, it is a different protocol from FTP and FTPS, which fortrabbit does not offer. Choose SFTP in the client.

## SFTP command line interface

The `sftp` command line tool is available on most Unix-like systems, including macOS and Linux.

```bash
# Connect to your environment via SFTP
sftp {{app-env-id}}@ssh.{{region}}.frbit.app

# Example: Upload a file
put /path/to/local/file.txt /path/to/remote/file.txt

# Example: Download a file
get /path/to/remote/file.txt /path/to/local/file.txt
```

## Alternatives

Alternatives to SFTP:

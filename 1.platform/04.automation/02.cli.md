## About the CLI

The CLI is a client of the [public API](/1.platform/04.automation/01.api.md) — everything it does is an API call, and it authenticates with the same personal API token. Nothing is exposed through the CLI that the API does not already offer.

It ships as a self-contained binary with no runtime dependency, so it also fits into CI pipelines and containers.

## Scope

Reach for the CLI when a person or a script drives the work from a terminal. For an AI agent, the [MCP server](/1.platform/04.automation/03.mcp.md) is the better fit, because the agent discovers the available actions instead of being told the command names.

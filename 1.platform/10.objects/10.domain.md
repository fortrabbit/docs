## Default domain

Each environment gets a [default domain](/1.platform/13.domains/01.default-domain.md) like `en-34fdsa.eu-w1a.frbit.app`. It is fixed, always on, and can not be deleted.

## External domain

An "external domain" is a domain registered with a third party domain name registrar. fortrabbit does not provide domain registration services:

- [Domain provider integration](/4.integrations/02.dns/01.intro.md) - combine domain provider with fortrabbit
- [External domains intro](/1.platform/13.domains/03.external-domains.md) - options and limits
- [Point an external domain](/1.platform/13.domains/04.external-domain-setup.md) - step by step instructions

## Target settings

For most domains the target can be changed. Target settings can not be changed for:

- apex domains: will always forward to their www counterpart
- main domains: define a different main domain first

### Environment setting

Change the environment of an external domain with this setting. External domains can be moved to another environment of the same app without DNS changes. This can be useful when switching the production domain to a new environment.

### Root path setting

A root path is a folder in the [file system](/1.platform/05.code-access/05.directories.md) of the [environment](/1.platform/10.objects/02.environment.md) where a domain will end. The root path is saved with the environment for all its domains. That means no interface is offered to configure individual root paths per domain. Route domains to different folders in the code instead, with `.htaccess` rules or the routing of the software.

### Domain forwarding

The dashboard allows you to forward domains with the same environment. Usually you will want to forward all domains to your main domain. See the [www domain forwarding article](/1.platform/13.domains/05.domain-forwarding-service.md).

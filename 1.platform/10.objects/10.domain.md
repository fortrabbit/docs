## Domain types

| Type            | Example                      | DNS setup | Move to          |
| --------------- | ---------------------------- | --------- | ---------------- |
| Default domain  | `en-34fdsa.eu-w1a.frbit.app` | None      | Not possible     |
| Cloud domain    | `my-shop.frbit.cloud`        | None      | Any app          |
| External domain | `www.example.com`            | Required  | Same app         |

All three are served over HTTPS with free TLS certificates.

### Default domain

Each environment gets a [default domain](/1.platform/13.domains/01.default-domain.md) built from its environment ID. It is fixed, always on, and can not be deleted. It was called test domain before.

### Cloud domain

A [cloud domain](/1.platform/13.domains/02.cloud-domain.md) is an optional name picked under frbit.cloud. fortrabbit handles the DNS. It can move to an environment of another app, the address stays the same.

### External domain

An external domain is registered with a domain provider. fortrabbit does not register domains:

- [Domain provider integration](/4.integrations/02.dns/01.intro.md) - combine domain provider with fortrabbit
- [External domains intro](/1.platform/13.domains/03.external-domains.md) - options and limits
- [Point an external domain](/1.platform/13.domains/04.external-domain-setup.md) - step by step instructions

## Target settings

Most domains can change their target. Two cannot:

- Apex domains always forward to their www subdomain.
- The main domain stays until another domain becomes the main domain.

### Environment setting

An external domain can move to another environment of the same app without DNS changes, for example to switch production to a new environment. A cloud domain can also move to an environment of another app.

### Root path setting

The [root path](/1.platform/07.settings/12.root-path.md) is set per [environment](/1.platform/10.objects/02.environment.md) and applies to all its domains. To serve different folders per domain, use `.htaccess` rules or the routing of the software.

### Domain forwarding

A domain can forward to another domain of the same environment, usually to the main domain. See [domain forwarding](/1.platform/13.domains/05.domain-forwarding-service.md).

## Understand individual access

Classic hosting often shares one login in a group. On fortrabbit, each account belongs to one person, see [account organization](/1.platform/03.concepts/01.account-organization.md).

## Developers and clients

An account is a developer or a client, chosen at sign-up and changeable later. Developers manage hosting and maybe billing, clients only billing. See [account types](/1.platform/20.collaboration/7.account-types.md).

## Code access

Developers add their public [SSH keys](/1.platform/10.objects/12.ssh-key.md) to the account for [code access](/1.platform/05.code-access/01.intro.md).

## Account settings

The account settings hold the login, name, e-mail address and other personal settings.

## GitHub app

For Git deployment, developers connect their GitHub account and install the [fortrabbit GitHub App](/1.platform/06.deployment/02.github-app.md).

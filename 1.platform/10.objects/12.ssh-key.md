An account belongs to one [person](/1.platform/10.objects/03.person.md), and SSH keys identify that person for [code access](/1.platform/05.code-access/01.intro.md). Passwords are not accepted. New to SSH keys? See [SSH key setup](/3.dev/15.learn/01.ssh-key-setup.md).

## Adding SSH keys to fortrabbit

:BlockLink{title="Add a new SSH key" path="/new/ssh-key"}

Paste the public key, the file ending in `.pub`, never the private one. Copy it to the clipboard:

```shell
# macOS
$ pbcopy < ~/.ssh/id_ed25519.pub

# Linux
$ xclip -selection clipboard < ~/.ssh/id_ed25519.pub

# Windows
# Open the `id_ed25519.pub` file, select all, then copy.
```

## Personal keys

:BlockLink{title="Manage your SSH keys" path="/you/ssh-keys"}

Personal keys belong to the developer account. They work on every environment the account has a [developer connection](/1.platform/20.collaboration/6.developer-connection.md) to, for SSH, SFTP and database tunnels. The SSH keys page of an environment lists the personal keys that have access.

## Deploy keys

A deploy key gives a service access to one environment, without a person behind it, for example a CI pipeline on [another Git host](/4.integrations/03.git-providers/01.intro.md) that deploys by rsync. Manage deploy keys in the SSH keys settings of the environment.

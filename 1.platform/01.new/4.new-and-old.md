Both platforms are live today. The table below shows the key differences at a glance.

|                   | Old Platform                                                 | New Platform                                       |
| ----------------- | ------------------------------------------------------------ | -------------------------------------------------- |
| **Dashboard**     | [dashboard.fortrabbit.com](https://dashboard.fortrabbit.com) | [dash.fortrabbit.com](https://dash.fortrabbit.com) |
| **Documentation** | [help.fortrabbit.com](https://help.fortrabbit.com)           | [docs.fortrabbit.com](https://docs.fortrabbit.com) |
| **State**         | Feature complete                                             | [BETA](/1.platform/01.new/3.beta.md)               |
| **Stability**     | Battle tested                                                | Good                                               |
| **Established**   | 2013                                                         | 2025                                               |
| **End of life**   | ~2027                                                        | Not planned                                        |

**The old platform** stays fully functional and supported until its end of life, planned for about 2027.

**The new platform** is live and open to everyone. See [what changed](/1.platform/01.new/5.changes.md).

## New customers

Start with the new platform.

## Existing customers

Both platforms can be used at the same time. **Accounts are not transferred yet.** Create a new account on the new platform with the same e-mail address, so the migration can match them later. Create new apps on the new platform, and keep managing existing apps on the old one.

## Timeline

The old platform runs until the [migration program](/1.platform/01.new/9.migration.md) has moved the apps. The migration starts after the new platform reaches general availability.

### Milestones

- **2025** New platform launches in public BETA
- **Next** General availability, no date yet
- **Then** [Migration](/1.platform/01.new/9.migration.md) old → new
- **~2027** Old platform end of life

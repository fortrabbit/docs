## Goals of the BETA

- Gather feedback from real-world apps
- Harden the platform and catch edge cases
- Complete the missing features

## Missing features

These features are planned and not available yet:

- Event log in the dashboard
- Key-value store component, based on Valkey
- Git hosts other than GitHub for push to deploy, see the [Git providers](/4.integrations/03.git-providers/01.intro.md)
- PHP 7.4, 8.0 and 8.1 as paid [legacy PHP versions](/1.platform/07.settings/06.php.md#legacy-php-versions)

## Stability

fortrabbit offers a **98% uptime SLA during the BETA**. Monitoring is in place, and the status page shows it: [fortrabbit.betteruptime.com](https://fortrabbit.betteruptime.com/).

New releases go out about once a week. Each one passes automated tests and a manual check on a staging cluster before it reaches production.

## Old platform during the BETA

The old platform keeps running during the BETA and beyond: [new and old run side by side](/1.platform/01.new/4.new-and-old.md). Existing customers need not hurry. The [official migration](/1.platform/01.new/8.migration/2.official.md) starts after general availability.

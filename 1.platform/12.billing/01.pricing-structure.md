An example [payment method](/1.platform/10.objects/09.payment-method.md) with two [apps](/1.platform/10.objects/01.app.md), one with one [environment](/1.platform/10.objects/02.environment.md) and one with two. Each environment books its own [plans](/1.platform/12.billing/20.plans.md) of [components](/1.platform/03.concepts/03.components.md).

```raw
- App 1 (takas)
  - Environment (production)
    - Components
      - PHP SM
      - Storage XS
      - Traffic XS
      - Backups XS
      - MySQL off
      - …
- App 2 (project-earth)
  - Environment (production)
    - Components
      - PHP MD
      - Storage MD
      - MySQL LG
  - Environment (staging)
    - Components
      - …
```

The pricing page shows the price of each plan: [fortrabbit.com/pricing](https://www.fortrabbit.com/pricing).

A GUI browses and edits the data, helps with queries, and keeps the remote and the local database as saved connections side by side.

## General instructions

fortrabbit accepts database connections through an SSH tunnel only. MySQL GUIs support this, usually in an SSH tab of the connection settings:

- SSH part
  - **SSH Host**: `ssh.{{region}}.frbit.app`
  - **SSH User**: `{{app-env-id}}`
  - **SSH Keyfile**: Your local SSH private key
- MySQL part
  - **MySQL Host**: `mysql`
  - **MySQL Server Port**: `3306`
  - **Username**: `{{app-env-id}}`
  - **Password**: Look it up in the dashboard
  - **Default Schema**: `{{app-env-id}}`

## Troubleshooting

The most common issues setting up the remote connection via database GUI are:

- Using no tunnel. Connect via SSH tunnel.
- Using localhost. Hostname is `mysql`.
- `Authentication requires secure connection` from the `caching_sha2_password` plugin. The client connects without TLS and the server has no cached login for the user yet, as with a new environment or after a MySQL restart. Enable the client's public key option, in Sequel Ace **Get Public Key**, or set its SSL mode to preferred.

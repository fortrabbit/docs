## Get ready

Syncing a database between a local and a remote environment requires:

- Have a [local development environment](/4.integrations/01.local-development/01.intro.md) running.
- Be able to [access the remote fortrabbit database](/1.platform/08.mysql/01.access/01.intro.md).

A sync moves the complete database: a `dump.sql` file with structure and contents, exported from the source and imported into the destination. It works in both directions:

- **Upload**: Export from local and import to fortrabbit
- **Download**: Export from fortrabbit and import to local

At setup, the local database usually goes up once. Later, as editors add content in production, it comes down from time to time. The [backup files](/1.platform/25.backups/files.md) hold a dump too.

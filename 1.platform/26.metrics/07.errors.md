## Counting errors

Each error metric counts the responses with that status code, for PHP and static files alike. A sample holds the responses since the sample before, a bar is the sum of its samples. In the box, the bare number is the count for the whole time frame, max and min are the busiest and the quietest hour or day.

Links below each chart open the access log filtered to that status code, for 500 and 504 also the PHP error log.

| Metric     | Status                | Usual cause                              | Read more                                         |
| ---------- | --------------------- | ---------------------------------------- | ------------------------------------------------- |
| 404 errors | Not found             | Missing file, broken link, crawler       | [404 errors](/3.dev/22.http-status-codes/404.md)  |
| 500 errors | Internal server error | Unhandled error in the code              | [500 errors](/3.dev/22.http-status-codes/500.md)  |
| 503 errors | Service unavailable   | All PHP processes busy, or PHP down      | [503 errors](/3.dev/22.http-status-codes/503.md)  |
| 504 errors | Gateway timeout       | PHP took longer than the time limit      | [504 errors](/3.dev/22.http-status-codes/504.md)  |

## Jobs memory

The memory the workers and crons use together. A sample holds the highest memory since the sample before, so it catches short spikes. A bar shows two values:

- max: the highest sample of the hour or day. Compare it with the memory of the Jobs plan, drawn as a line.
- typical peak: the median sample. Half of the samples were lower, half higher.

See [overlapping jobs](/1.platform/30.jobs/05.tuning.md#overlapping-jobs) and [out of memory](/3.dev/02.performance/10.out-of-memory.md#jobs).

## Jobs OOM kills

Workers and crons the system ended because the jobs needed more memory than the plan has. A bar is the number of kills in that hour or day. See [out of memory](/3.dev/02.performance/10.out-of-memory.md#jobs).

## MySQL storage

The space the database of the environment uses. A sample holds the size at that moment. A bar shows four values from its samples:

- max: the largest size of the hour or day
- last: the size at the end of the hour or day
- avg: the average size
- min: the smallest size

The lines mark the storage of each MySQL plan. See [why MySQL storage grows](/1.platform/09.components/02.mysql.md#why-mysql-storage-grows) and [autoscaling](/1.platform/12.billing/11.autoscaling.md).

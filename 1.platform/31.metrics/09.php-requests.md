## About PHP requests

Each bar counts the requests the load balancer passed on to PHP in its hour or day. Requests for existing files skip PHP and count as [static requests](/1.platform/31.metrics/04.static-requests.md). The summary shows the total of the time frame and the highest and lowest bar. The table lists the URLs by count, with their average response time.

:BlockLink{title="See PHP requests for {{app-env-name}}" path="/environments/{{app-env-id}}/metrics/php-requests"}

## What to look for

A PHP request is not a page view. One page view can trigger several PHP requests: the page itself, AJAX calls, image transforms, a form submit. Bots, uptime checks, and cron URLs add requests without any visitor. A [web analytics tool](/4.integrations/11.web-analytics/01.intro.md) counts people, this metric counts work.

## What to do

Compare with [PHP response time](/1.platform/31.metrics/08.php-response-time.md). More requests at the same response time is healthy. More requests with rising response times or [503 errors](/1.platform/31.metrics/18.error-503.md) mean all PHP processes are busy. Check the top URLs in the table: cache what can be cached, block unwanted bots, or scale the [PHP component](/1.platform/09.components/01.php.md#scaling).

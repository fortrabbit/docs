## About 504 errors

The load balancer counts every response with status 504, for PHP and static files alike. The summary shows the total of the time frame.

:BlockLink{title="See 504 errors for {{app-env-name}}" path="/environments/{{app-env-id}}/metrics/error-504"}

## What to look for

A 504 is the far end of [PHP response time](/1.platform/31.metrics/06.php-response-time.md): the request ran longer than the limit. A few come from long exports or imports. Many at once, together with rising response times, mean slow code or a slow database under load.

## What to do

Find the URLs in the [access logs](/1.platform/07.settings/25.logs.md#access-logs) filtered by status `504`. Move long tasks to [jobs](/1.platform/30.jobs/index.md), speed up slow queries, and add caching. Scale the [PHP component](/1.platform/09.components/01.php.md#scaling) only when the code is fast and the load is high. See [troubleshoot 504 errors](/3.dev/22.http-status-codes/504.md).

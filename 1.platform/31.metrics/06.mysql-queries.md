## About MySQL queries

Each bar counts the statements of its hour or day. The summary shows the total of the time frame and the highest and lowest bar. The table lists the queries by count, with their average duration.

:BlockLink{title="See MySQL queries for {{app-env-name}}" path="/environments/{{app-env-id}}/metrics/mysql-queries"}

## What to look for

Queries follow [PHP requests](/1.platform/31.metrics/09.php-requests.md). More queries at the same request count means each page asks the database more often. One query that runs thousands of times per hour often points to an N+1 problem: a loop that loads one row per iteration. A high average duration points to a missing index.

## What to do

Start with the top rows of the table. Load related rows in one query instead of a loop, cache results that rarely change, and add indexes for slow lookups, see [database performance](/3.dev/02.performance/08.database.md). Scale the [MySQL component](/1.platform/09.components/02.mysql.md#scaling) only when the queries are efficient and the load is real.

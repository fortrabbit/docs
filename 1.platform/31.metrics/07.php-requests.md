## About PHP requests

The load balancer counts each request it passes on to PHP. Requests for existing files are served without PHP and show up as [static requests](/1.platform/31.metrics/04.static-requests.md) instead. The summary shows the total of the time frame and the highest and lowest bar.

:BlockLink{title="See PHP requests for {{app-env-name}}" path="/environments/{{app-env-id}}/metrics/php-requests"}

## What to look for

A PHP request is not a page view. One page view can trigger several PHP requests: the page itself, AJAX calls, image transforms, a form submit. Bots, uptime checks and cron URLs add requests without any visitor. A [web analytics tool](/4.integrations/11.web-analytics/01.intro.md) counts people, this metric counts work.

## What to do

Compare the count with [PHP response time](/1.platform/31.metrics/06.php-response-time.md). More requests at the same response time is healthy. More requests with rising response times or [503 errors](/1.platform/31.metrics/15.error-503.md) means all PHP processes are busy: cache pages where possible, block unwanted bots, or scale the [PHP component](/1.platform/09.components/01.php.md#scaling).

## About static requests

Requests for an existing file are served from disk, the others go to PHP. Each bar counts the first kind for its hour or day. The summary shows the total of the time frame and the highest and lowest bar. The table lists the files by request count, with the traffic they caused.

:BlockLink{title="See static requests for {{app-env-name}}" path="/environments/{{app-env-id}}/metrics/static-requests"}

## What to look for

Static requests use no PHP processes, so a high count costs little capacity. They still add to [traffic](/1.platform/31.metrics/03.traffic.md). A page that loads 80 small files makes 80 static requests per visit, which also slows the page down.

## What to do

Bundle scripts and stylesheets, and set cache headers so returning visitors load assets from the browser cache. A spike without more visitors often comes from a crawler or a hotlinked image: the table shows which file, the [access logs](/1.platform/07.settings/25.logs.md#access-logs) show who asked.

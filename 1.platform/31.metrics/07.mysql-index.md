## About MySQL index

Each bar is the highest index size of its hour or day. The summary shows the current value and the highest and lowest of the time frame.

:BlockLink{title="See MySQL index for {{app-env-name}}" path="/environments/{{app-env-id}}/metrics/mysql-index"}

## What to look for

Indexes grow with the tables they belong to, so slow growth is normal. Indexes that grow faster than the data, or take more space than the data itself, point to redundant indexes or indexes on columns nobody queries. Compare with [MySQL storage](/1.platform/31.metrics/05.mysql-storage.md) for the same time frame.

## What to do

List the indexes per table in a [MySQL client](/1.platform/08.mysql/01.access/01.intro.md). Drop duplicates and indexes no query uses. CMS plugins and migrations add indexes over time, so check after updates.

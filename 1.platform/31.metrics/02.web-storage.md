## About web storage

The chart shows the used space of the environment's persistent storage. Each bar is the highest value sampled in its hour or day. The summary shows the current value and the highest and lowest of the time frame. Horizontal lines mark storage plan sizes.

:BlockLink{title="See Web storage for {{app-env-name}}" path="/environments/{{app-env-id}}/metrics/web-storage"}

## What to look for

Storage grows with each upload and with every file the app writes. A steady climb is expected for a site that collects uploads. A steep or sudden climb usually has a cause in the code: cache files that never expire, log files written to disk, image transforms generated for every crawler request, or backups stored inside the environment.

## What to do

Find the large directories over [SSH](/1.platform/05.code-access/03.ssh.md) with `du -sh *`, then delete or move what does not belong there. The [storage component](/1.platform/09.components/03.storage.md#scaling) page lists common causes. When the growth is real, scale the storage plan or enable [autoscaling](/1.platform/12.billing/11.autoscaling.md).

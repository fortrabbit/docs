## About MySQL storage

The chart shows the used storage of the MySQL database, tables and indexes included. Each bar is the highest value sampled in its hour or day. The summary shows the current value and the highest and lowest of the time frame. Horizontal lines mark MySQL plan sizes.

## What to look for

A database grows with content. Fast growth usually comes from tables nobody reads: sessions, cache entries, search indexes, revision histories or plugin logs. A crawler that creates entries, for example through a search form, can fill a table within days.

## What to do

List the largest tables in a [MySQL client](/1.platform/08.mysql/01.access/01.intro.md), then clean up or limit what fills them. The [MySQL component](/1.platform/09.components/02.mysql.md#scaling) page covers common causes. When the growth is real, scale the MySQL plan or enable [autoscaling](/1.platform/12.billing/11.autoscaling.md).

There are no one-click installers. The software guides cover deploying and configuring an existing code base. Support answers general hosting and PHP questions for any software, and goes deeper for some.

## A grade support

Solid hands-on experience. Ask anything about [Craft CMS](/2.guides/3.craft-cms/index.md), [Laravel](/2.guides/2.laravel/index.md) and [Symfony](/2.guides/7.more/08.symfony.md).

## B grade support

Install and deployment are known, with less hands-on experience: [WordPress](/2.guides/6.wordpress/index.md), [Statamic](/2.guides/5.statamic/index.md), [Kirby](/2.guides/4.kirby/index.md), [Filament](/2.guides/2.laravel/06.filament.md) and October CMS.

## C grade support

The software runs on fortrabbit, and some clients use it, but support can help little beyond general PHP hosting: Drupal, TYPO3, Grav, Shopware, CakePHP, CodeIgniter, Yii, Winter CMS, Bolt CMS, Tempest, Leaf, Lunar, Twill, Hyde, Jigsaw and other PHP software.

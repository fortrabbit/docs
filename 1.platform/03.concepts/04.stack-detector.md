Connecting a GitHub repository to a new app for [Git deployment](/1.platform/06.deployment/01.intro.md) runs the stack detector over the code. The source is on GitHub: [fortrabbit/stack-detector](https://github.com/fortrabbit/stack-detector).

It recognizes the software and its major version, and applies the matching [software template](/1.platform/03.concepts/05.software-templates.md). From `composer.json` and `package.json` it sets the [build commands](/1.platform/06.deployment/03.build-commands.md):

- With a `composer.json`: `composer install --no-dev --prefer-dist --no-interaction --no-ansi --no-progress`
- With a `package.json`: `install` and `run build` with the package manager its lock file names: npm, pnpm, yarn or Bun

npm and pnpm are installed in the build. For yarn and Bun, see the [limits of the build](/1.platform/06.deployment/03.build-commands.md#limits-of-the-build).

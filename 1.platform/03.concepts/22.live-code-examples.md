## Example

| Not parsed          | Parsed             | Description               |
| ------------------- | ------------------ | ------------------------- |
| `{​{app-name}}`     | `{{app-name}}`     | Selected app name         |
| `{​{region}}`       | `{{region}}`       | Region of selected app    |
| `{​{app-env-name}}` | `{{app-env-name}}` | Selected environment name |
| `{​{app-env-id}}`   | `{{app-env-id}}`   | Selected environment id   |

<!-- Invisible white space used to render not parsed for everyone, don't copy from here -->

Logged in to the dashboard, choose an [environment](/1.platform/10.objects/02.environment.md) with the select next to the article, and the parsed column shows its values. Without a login, the placeholders stay in double curly braces.

- You are not logged in when 'not parsed' and 'parsed' look the same to you
- You are logged in when 'not parsed' and 'parsed' look different to you

## Deep links

Deep links let logged-in users jump to the dashboard directly from docs. Here's an example:

:BlockLink{title="Change plans for {{app-env-name}}" path="/environments/{{app-env-id}}/components"}

- Logged in users see a link
- Unknown users see a message to login to see the link

## Cookie

A functional cookie holds the login state of the dashboard and the list of environments. Clearing the cookies resets the selection.

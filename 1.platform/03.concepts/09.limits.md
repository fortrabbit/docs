## This is not VPS hosting

fortrabbit runs each [environment](/1.platform/10.objects/02.environment.md) as a lightweight container, built to deliver PHP fast. Each [component](/1.platform/03.concepts/03.components.md) scales on its own. Anyone looking for the most hardware per euro is better served by a VPS.

## No 1-click installers

The software chosen for a new app sets the [software template](/1.platform/03.concepts/05.software-templates.md). It does not install the software.

## No root shell

[SSH](/1.platform/05.code-access/03.ssh.md) works for deployment and everyday development tasks, without root. Software cannot be installed at runtime, such as a mail server, Ruby or a global npm package. Node.js runs during the deployment only, in the [build commands](/1.platform/06.deployment/03.build-commands.md).

## Executable scripts

Scripts need the executable bit to run directly. Without it, call PHP files through the interpreter: `php artisan` or `php craft`. See [executing scripts](/1.platform/05.code-access/03.ssh.md#executing-scripts).

## Heavy tools in jobs only

ffmpeg, Ghostscript, Chromium and image optimizers such as `jpegoptim`, `optipng`, `pngquant` and `gifsicle` use a lot of CPU time and memory. They are installed for [jobs](/1.platform/09.components/07.jobs.md) only, so they never slow down web requests. Move video conversion, image optimization or PDF rendering into a worker or a cron.

## PDF creation

wkhtmltopdf is not installed and cannot be installed. Alternatives:

- [dompdf](https://github.com/dompdf/dompdf), a PHP library that renders HTML and CSS to PDF
- A PDF service
- PDF creation in the browser, with [jsPDF](https://github.com/parallax/jsPDF) or similar

## Security responsibilities

fortrabbit takes care of the operating system and the PHP runtime. The developer is responsible for the code and the software it uses.

## Service location

The region of an app is chosen at creation and cannot be changed later. Billing is in euros or US dollars, chosen per [payment method](/1.platform/10.objects/09.payment-method.md). fortrabbit is based in Berlin.

## Mailing

PHP's `mail()` function calls `sendmail`, which does not exist on fortrabbit. Mail servers reject most mail sent directly from a web server anyway. Use a [transactional mail provider](/4.integrations/10.transactional-mail/01.intro.md), or SMTP with a mail provider: the SMTP ports 25, 465 and 587 are open in the [outgoing firewall](/1.platform/07.settings/21.firewall-outgoing.md).

## Structure

Default domains follow a fixed pattern:

```raw
{{ environment }}.{{ region }}.frbit.app

environment — ID, short unique identifier
region — data center region ID, geo location
frbit.app — fortrabbit associated root domain
```

- Example: `https://en-34fdsa.eu-w1a.frbit.app`
- [Live code](/1.platform/03.concepts/22.live-code-examples.md) example: `{{app-env-id}}.{{region}}.frbit.app` (login required)
- TLS is included. The default domain is always served over HTTPS.

## Use cases

- Open the environment in a browser right after the first deploy, without any setup.
- Send work in progress to a colleague.
- Reference the environment in automated tests or health checks: the address never changes.

For an address people remember, add a [cloud domain](/1.platform/13.domains/02.cloud-domain.md).

## Limits

- The name cannot be changed. The environment ID part of the default domain is fixed at environment creation time.
- The default domain cannot be deleted or moved to another environment.
- The default domain is not a replacement for a production domain. For a customer-facing address, add an [external domain](/1.platform/13.domains/03.external-domains.md).

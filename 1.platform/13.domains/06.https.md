## HTTPS on fortrabbit

Every correctly routed external domain gets a TLS certificate, without any setup. Default domains and cloud domains are always served over HTTPS. Certificates renew automatically.

## HTTPS options

### HTTP to HTTPS redirect

fortrabbit answers every request on `http://` with a 301 redirect to `https://`, no setup needed. To make browsers skip `http://` entirely, set [HSTS](/3.dev/21.htaccess/06.hsts.md).

### Secure your domain with a CAA record

A Certification Authority Authorization (CAA) record names the certificate authorities that may issue certificates for a domain. fortrabbit uses Let's Encrypt. A domain with CAA records needs one for `letsencrypt.org`, or the certificate fails, see the [Let's Encrypt CAA docs](https://letsencrypt.org/docs/caa).

## About HTTPS, TLS & SSL

HTTPS encrypts the connection between browser and server. It runs on TLS (Transport Layer Security), the successor of SSL, a name still in common use. Browsers warn about websites without HTTPS.

## About cloud domains

Every environment has a [default domain](/1.platform/13.domains/01.default-domain.md) built from its ID. A cloud domain adds a readable name next to it. It is optional, and fortrabbit handles the DNS, so it works once it is created.

- Show a client the development version under a name they can remember.
- Switch a staging address to a new environment without telling anyone a new URL.
- Run a pet project without registering a domain.

TLS is included, the cloud domain is served over HTTPS.

## Cloud domain and default domain

|                             | Default domain | Cloud domain |
| --------------------------- | -------------- | ------------ |
| Name                        | Environment ID | Picked       |
| Created                     | Automatically  | On request   |
| Move to another environment | No             | Yes          |
| Delete                      | No             | Yes          |
| Per environment             | One            | One at most  |

## Picking a name

Add a cloud domain when creating an app or an environment, or later in the dashboard under domains. App creation suggests a name from the app name.

- Lowercase letters, digits, and hyphens
- No hyphen at the start or the end
- One label only: `my-shop.frbit.cloud` works, `staging.my-shop.frbit.cloud` does not

Names are unique across fortrabbit, first come, first served. A taken name gets a suggestion with a number, like `my-shop-2`. Some names are reserved, for example `admin`, `login`, `mail`, or `www`, and words that invite phishing, like `paypal` or `secure`.

## Moving to another environment

A cloud domain can move to any environment of any app with developer access, also in another region. The address stays the same, no DNS change is needed. An environment holds one cloud domain at most, so environments that have one can not be picked. To swap two cloud domains, delete one first, move the other, then create the first again.

## Limits

- **The name can not be changed.** Delete the cloud domain and create a new one.
- **A deleted name is free again.** Someone else can pick it, so don't delete a name a client still uses.
- **Deleting an environment deletes its cloud domain.** Move the cloud domain first to keep it.
- For a customer-facing production address, add an [external domain](/1.platform/13.domains/03.external-domains.md).

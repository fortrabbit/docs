## 1. Add the domain in the dashboard

Add the domain to an environment in the dashboard. The dashboard then shows the DNS records to set.

1. Click New > "Add a new domain"
2. Choose the environment, the type "external domain", then enter the domain name
3. Keep the domain overview open to copy the DNS records

:BlockLink{title="Add a new domain" path="/new/domain"}

## 2. Point the domain to fortrabbit

Set the records from the dashboard with the domain provider.

- For subdomains like www, use the CNAME record
- Apex domains get an A record for [forwarding](/1.platform/13.domains/05.domain-forwarding-service.md)
- Leave any other records untouched, especially MX
- Remove any AAAA records (IPv6)

Save the settings and wait for DNS propagation. How long that takes depends on the TTL of the old records.

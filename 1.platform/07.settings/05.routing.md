## Default domain

Each [environment](/1.platform/10.objects/02.environment.md) gets a [default domain](/1.platform/13.domains/01.default-domain.md) on frbit.app, such as `{{app-env-id}}.{{region}}.frbit.app`. It works right after creation, without DNS setup. Use it for development, testing and [staging environments](/3.dev/15.learn/03.staging-environments.md). The environment overview in the dashboard shows it.

## External domains

An environment accepts requests for every [external domain](/1.platform/13.domains/03.external-domains.md) added to it in the domain settings of the app. The DNS of the domain has to point to fortrabbit, see the [domain setup](/1.platform/13.domains/04.external-domain-setup.md). All domains of an environment land in the same [root path](/1.platform/07.settings/12.root-path.md).

## Main domain

The main domain is the one domain of an environment the platform uses as its address: for the thumbnail preview in the dashboard, for monitoring, and in the `FORTRABBIT_MAIN_DOMAIN` [ENV var](/1.platform/07.settings/01.env-vars.md). Choose it in the environment settings, once the environment has at least two domains.

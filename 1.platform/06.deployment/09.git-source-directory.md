The Git source directory is part of the deployment settings of an environment. Empty means the repository root, which fits most apps. [Exclude](/1.platform/06.deployment/10.exclude-patterns.md) and [replace patterns](/1.platform/06.deployment/15.replace-patterns.md) start from this folder.

::CallOut
When the repository contains a [deploy file](/1.platform/06.deployment/06.deploy-file.md), this setting is managed there and cannot be edited in the dashboard.
::

## Use cases

A [monorepo](/3.dev/15.learn/04.monorepos.md) holds several projects in one Git repository. Each environment deploys one of them, for example `apps/website-1`. The [root path](/1.platform/07.settings/12.root-path.md) is then relative to that folder.

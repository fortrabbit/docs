Replace patterns need the merge [deployment strategy](/1.platform/06.deployment/08.strategy.md). Merge copies the deploy package over the storage and deletes nothing, so a file removed in Git stays in the storage. For a folder matched by a replace pattern, the deployment deletes the old content first.

::CallOut
When the repository contains a [deploy file](/1.platform/06.deployment/06.deploy-file.md), this setting is managed there and cannot be edited in the dashboard.
::

The [software template](/1.platform/03.concepts/05.software-templates.md) sets defaults, such as the project config folder of Craft CMS: a stale config file there would be applied again. Patterns follow rsync syntax: `*` matches any characters, a leading `/` anchors the pattern at the [Git source directory](/1.platform/06.deployment/09.git-source-directory.md).

## Examples

```yml
## Craft CMS
/config/project

## Pattern to replace all JPGs
*.jpg
```

## Exclude patterns

[Exclude patterns](/1.platform/06.deployment/10.exclude-patterns.md) are the counterpart: they keep files and folders out of the deployment. They work with both strategies.

## Get ready

- Experience [with Git](/3.dev/15.learn/git-intro.md)
- The [deployment intro](/1.platform/06.deployment/01.intro.md)
- An account on fortrabbit and one on GitHub

## Installation

Install the [fortrabbit GitHub App](https://github.com/apps/fortrabbit) on GitHub, during the sign-up with GitHub or later in the account settings of the dashboard. GitHub asks for:

- The account or organization to install it on
- Access to the repos, and permission to create repos

## Connect, create or change a repo

A Git repo maps to an [app](/1.platform/10.objects/01.app.md) on fortrabbit. Creating an app asks for an existing repo or creates a new empty one. The repo of an app can be changed later.

## Connect, create or change a branch

A Git branch maps to an [environment](/1.platform/10.objects/02.environment.md). Create one environment per branch, for example `main` for production and `staging` for a [staging environment](/3.dev/15.learn/03.staging-environments.md).

## Repos from organizations at GitHub

Repos of a GitHub organization are available once the fortrabbit GitHub App is installed on that organization.

## Who can deploy

By default, every push to the connected branch deploys, no matter who sent it. Limit git push deployments to developers connected to the app with the [deployment permission](/1.platform/06.deployment/18.permission.md) setting of the environment.

## GitHub Actions

GitHub Actions run tests or other steps before code reaches fortrabbit. Combine them with the Git deployment, a [deploy hook](/1.platform/06.deployment/16.deploy-hook.md) or [code access](/1.platform/05.code-access/01.intro.md). See [GitHub with an example](/4.integrations/03.git-providers/02.github.md).

## Removing access

Uninstalling the fortrabbit GitHub App on GitHub stops all deployments of the connected apps. Closing a fortrabbit account does not uninstall the app on GitHub.

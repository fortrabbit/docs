## Push to deploy

The default. Every push to the Git branch connected to the [environment](/1.platform/10.objects/02.environment.md) deploys, as far as the [deployment permission](/1.platform/06.deployment/18.permission.md) allows. The [fortrabbit GitHub App](/1.platform/06.deployment/02.github-app.md) receives the push events from GitHub.

## Manual deployment

With manual deployment, pushes do not deploy. Deploy with the Deploy now button, or with a [deploy hook](/1.platform/06.deployment/16.deploy-hook.md).

## Deploy now button

The Deploy now button in the deployment settings of the environment deploys the latest commit of the branch, with the current deployment settings.

:BlockLink{title="Deploy {{app-env-id}} now" path="/deploy/environment/confirm?environment={{app-env-id}}"}

It works with both triggers. Use it to apply a changed deployment setting without a new commit. An older commit cannot be deployed again: revert it in Git and push instead.

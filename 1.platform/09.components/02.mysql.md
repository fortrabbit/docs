Most CMS, such as [WordPress](/2.guides/6.wordpress/01.setup.md) and [Craft CMS](/2.guides/3.craft-cms/01.install.md), keep their content in MySQL.

## Booking MySQL

MySQL is optional. Each [environment](/1.platform/10.objects/02.environment.md) can book one MySQL component with one database. MySQL is the only database fortrabbit offers.

## Configuration

With MySQL booked, the environment gets MySQL settings and metrics in the dashboard. See [MySQL](/1.platform/08.mysql/01.access/01.intro.md) for access, import and export.

## Scaling

MySQL plans differ in storage. Up to LG they share memory, from XL up each plan has memory of its own. The number of connections comes with the [PHP plan](/1.platform/09.components/01.php.md). As a rule of thumb, scale both together: PHP XS with MySQL XS, PHP SM with MySQL SM. See [database performance](/3.dev/02.performance/08.database.md).

When [autoscaling](/1.platform/12.billing/11.autoscaling.md) is enabled, smaller and larger plans are automatically booked, based on MySQL storage usage. With autoscaling off, a full database stops accepting new rows, see [missing INSERT privileges](/1.platform/08.mysql/19.troubleshooting.md#missing-insert-privileges). Scale the plan or clean up the database.

## Why MySQL storage grows

The database grows as the app writes rows. The [metrics](/1.platform/07.settings/30.metrics.md) show how fast. Unwanted growth often comes from:

- Logs written to tables
- Revisions kept for every entry
- Bots that create entries, such as spam comments or search logs

### Cleaning up the database

Before scaling up, check what fills the database: [find the large tables](/1.platform/08.mysql/19.troubleshooting.md#query-large-tables), delete rows that are not needed, and fix the code or config that wrote them. The metric shows the new size after a few minutes.

## Without MySQL

Flat-file CMS such as [Kirby](/2.guides/4.kirby/index.md), [Statamic](/2.guides/5.statamic/index.md) and [Grav](/2.guides/7.more/07.grav.md) run without a database, and so do apps that only talk to APIs. Leave MySQL off for them.

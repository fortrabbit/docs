## Files down

Run it from the project root:

```shell
frbit files pull web/sites/default/files -e {{app-env-id}}
```

Changed files are overwritten locally. Add `--dry-run` to see what would change, `--delete` to also remove local files that are gone on the environment.

## Files up

```shell
frbit files push web/sites/default/files -e {{app-env-id}}
```

It asks to type the environment ID first. The software template [excludes](/1.platform/06.deployment/10.exclude-patterns.md) `web/sites/default/files` from deployments, so pushed files survive the next deployment.

## Without the frbit CLI

Both commands wrap [rsync](/3.dev/20.how-to/rsync.md) over SSH. The same with plain rsync:

```shell
# Down
rsync -av {{app-env-id}}@ssh.{{region}}.frbit.app:web/sites/default/files/ ./web/sites/default/files/

# Up
rsync -av ./web/sites/default/files/ {{app-env-id}}@ssh.{{region}}.frbit.app:web/sites/default/files/
```

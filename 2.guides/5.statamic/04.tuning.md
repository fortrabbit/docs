## Adding domains

Every environment starts with its [default domain](/1.platform/13.domains/01.default-domain.md). Add [external domains](/1.platform/13.domains/03.external-domains.md) for production. The template sets `APP_URL` to the [main domain](/1.platform/07.settings/05.routing.md#main-domain).

## Software template

The Statamic [software template](/1.platform/03.concepts/05.software-templates.md) sets the root path, the ENV vars for app and database, the build and post deploy commands, and the exclude patterns for the content:

:SoftwarePreset{slug="statamic"}

For an app created without the template, copy these settings by hand in the [ENV vars](/1.platform/07.settings/01.env-vars.md), the [root path](/1.platform/07.settings/12.root-path.md) and the deployment settings. Use the same `APP_KEY` locally and on fortrabbit.

## Working with the control panel

Editors manage content in the browser with the control panel at `/cp`, such as `{{app-env-id}}.{{region}}.frbit.app/cp`. How content moves depends on the [deployment option](/2.guides/5.statamic/02.deployment-options.md):

- **Content in Git**: edit locally only. A deployment overwrites edits made in the control panel on the server.
- **Content by rsync**: sync the edits made on the server down, see [Git and rsync](/2.guides/5.statamic/03.deploy-git-rsync.md).
- **Content in MySQL**: copy the database down from time to time, see [export and import](/1.platform/08.mysql/02.export-import/07.intro.md).

## Image presets

Statamic generates the [image presets](https://statamic.dev/image-manipulation) of a container on upload, and other Glide sizes on the first view of their URL. Both run in a PHP process of the site. Keep presets few and uploads small, see [image transforms](/3.dev/02.performance/12.image-transforms.md). To create missing presets, run `php please assets:generate-presets` over [SSH](/1.platform/05.code-access/03.ssh.md).

## Backups

The [backup component](/1.platform/09.components/05.backups.md) backs up files and database daily. Git holds the history of the code.

## Updating Statamic

Update locally first: run `composer update` in the project folder, test, then commit `composer.lock` and `git push`.

## Sending mails

fortrabbit has no [sendmail](/1.platform/03.concepts/09.limits.md#mailing). Statamic sends through Laravel mail: set the SMTP or API settings of a mail account or a [transactional mail provider](/4.integrations/10.transactional-mail/01.intro.md) as ENV vars, see [Statamic email](https://statamic.dev/advanced-topics/email).

## Getting a license

Statamic Core is free. Statamic Pro adds team features such as several users and roles, and needs a license, see [Statamic licensing](https://statamic.dev/getting-started/licensing).

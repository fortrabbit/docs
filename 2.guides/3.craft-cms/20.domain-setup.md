## Site URL

Craft's installer writes the local site URL into the `.env` file as `PRIMARY_SITE_URL` and uses `$PRIMARY_SITE_URL` as the base URL of the primary site. The `.env` file stays local and the software template does not set this ENV var, so add it to the [ENV vars](/2.guides/3.craft-cms/07.env-vars.md) of the environment:

```shell
PRIMARY_SITE_URL=https://${FORTRABBIT_MAIN_DOMAIN}
```

`FORTRABBIT_MAIN_DOMAIN` holds the main [domain](/1.platform/10.objects/10.domain.md) chosen for the environment. All domains of an environment share its [root path](/1.platform/07.settings/12.root-path.md), `web` for Craft CMS.

## Multi-site domains

Give each site its own ENV var, for example `SITE_URL_EN` and `SITE_URL_NL`, and enter `$SITE_URL_EN` as the base URL of that site under **Settings → Sites** in the local control panel. Set the local values in `.env` and the fortrabbit values in the ENV vars of the environment:

```shell
SITE_URL_EN=https://www.example.com
SITE_URL_NL=https://www.example.nl
```

Add all domains to the environment. Craft routes each request to the site whose base URL matches. Use [.htaccess rules](/3.dev/21.htaccess/01.intro.md) for redirects between the domains.

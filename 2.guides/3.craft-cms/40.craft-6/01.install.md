## Differences to Craft 5

Craft 6 is a rewrite on Laravel 13. The deploy setup follows Laravel, not Craft 5:

- PHP 8.5 or newer
- Webroot `public`, not `web`
- Commands run with `php artisan craft:…`, for example `php artisan craft:up`
- Database settings in `DB_*` ENV vars, not `CRAFT_DB_*`
- Craft filesystems are Laravel disks, set up in `config/filesystems.php`
- Queue and scheduler are Laravel's

Performance, caching and plugins are covered for Craft 5 only so far, in the [Craft CMS 5 guides](/2.guides/3.craft-cms/index.md). Moving from Craft 5 to 6? See the [Craft upgrade guide](https://craftcms.com/docs/6.x/upgrade.html).

## Get ready

- Have a [local development environment](/4.integrations/01.local-development/01.intro.md) running. [DDEV](/4.integrations/01.local-development/02.ddev.md) is recommended.
- Use PHP 8.5 or newer, locally and on fortrabbit.
- Keep the [official Craft CMS 6 install guide](https://craftcms.com/docs/6.x/install.html) at hand.

## Install with DDEV

Configure DDEV as a Laravel project with the `public` webroot and MySQL, then create the project. The setup wizard starts right after and asks for the admin account:

```shell
ddev config --project-type=laravel --docroot=public --php-version=8.5 --database=mysql:8.4
ddev composer create-project "craftcms/craft:^6.0.0-beta.1"
```

Use MySQL locally too. The Craft 6 skeleton defaults to PostgreSQL, and fortrabbit runs [MySQL](/1.platform/09.components/02.mysql.md). Then build the site locally with templates, sections, fields and content.

## Commit the project config

The install writes the project config to `config/craft/project/`. Commit that folder: deployments apply it on fortrabbit with `php artisan craft:up`.

## Set up GitHub

Put the project in a git repository on GitHub, here with the [GitHub CLI](/4.integrations/07.git-clients/02.gh-cli.md):

```shell
git init
git add .
git commit -m "Init"
gh repo create --private --source=. --push
```

The `.gitignore` of the skeleton keeps `.env`, `vendor` and the published Control Panel files in `public/vendor/craft` out of the repository. The build on fortrabbit installs `vendor` and publishes the Control Panel files, and the [ENV vars](/2.guides/3.craft-cms/40.craft-6/10.env-vars.md) of the environment take the place of `.env`. See the [deployment intro](/1.platform/06.deployment/01.intro.md) for how git deployment works.

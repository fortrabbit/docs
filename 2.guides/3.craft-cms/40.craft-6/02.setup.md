## Create an app

[Git deployment](/1.platform/06.deployment/01.intro.md) needs the [fortrabbit GitHub App](/1.platform/06.deployment/02.github-app.md) on the GitHub account. Then create a new app and connect the repository:

:BlockLink{title="Create a new app" path="/new/app"}

The [stack detector](/1.platform/03.concepts/04.stack-detector.md) recognizes Craft CMS 6 and picks version 6 of the Craft CMS [software template](/1.platform/03.concepts/05.software-templates.md). Without a repository, choose Craft CMS and version 6 by hand. The template sets:

- PHP 8.5
- Root path `public`
- The [ENV vars](/2.guides/3.craft-cms/40.craft-6/04.env-vars.md) for Laravel and the MySQL database
- The build and post-deploy commands, see [deployment](/2.guides/3.craft-cms/40.craft-6/03.deployment.md)

## Bring the database up

The first deployment starts right after the app is created, with an empty database. It fails at `php artisan craft:up`, because Craft is not installed there yet. Import the local database, which the install created:

1. [Database up](/2.guides/3.craft-cms/40.craft-6/05.database.md#database-up)
2. Lift the maintenance mode the failed deployment left on:

   ```shell
   ssh {{app-env-id}}@ssh.{{region}}.frbit.app php artisan up
   ```

3. Deploy again from the dashboard, or push a commit

## Install on fortrabbit instead

To start with an empty site on fortrabbit, install Craft over [SSH](/1.platform/05.code-access/03.ssh.md) after the first deployment:

```shell
ssh -t {{app-env-id}}@ssh.{{region}}.frbit.app
php artisan migrate --force
php artisan craft:install
php artisan up
```

`craft:install` asks for the admin account and site settings, and asks to confirm the run in production. The web installer does not work: Craft answers every request with a 503 error until it is installed. The next deployment deletes the project config the install wrote to `config/craft/project/`, and `craft:up` writes it again from the database. To develop locally, [pull the database down](/2.guides/3.craft-cms/40.craft-6/05.database.md#database-down) and commit the project config from there.

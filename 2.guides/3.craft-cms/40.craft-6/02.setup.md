## Create an app

[Git deployment](/1.platform/06.deployment/01.intro.md) needs the [fortrabbit GitHub App](/1.platform/06.deployment/02.github-app.md) on the GitHub account. Then create a new app and connect the repository:

:BlockLink{title="Create a new app" path="/new/app"}

The [stack detector](/1.platform/03.concepts/04.stack-detector.md) recognizes Craft CMS 6 and picks version 6 of the Craft CMS [software template](/1.platform/03.concepts/05.software-templates.md). Without a repository, choose Craft CMS and version 6 by hand. The template sets:

- PHP 8.5
- Root path `public`
- The [ENV vars](/2.guides/3.craft-cms/40.craft-6/04.env-vars.md) for Laravel and the MySQL database
- The build and post-deploy commands, see [deployment](/2.guides/3.craft-cms/40.craft-6/03.deployment.md)

## First deployment

The first deployment runs with an empty database, and passes: the post-deploy commands skip `php artisan craft:up` until Craft is installed. The site returns a 500 error until the database is up.

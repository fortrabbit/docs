## Git deployment

With the repository connected to the app, every `git push` to the deployment branch deploys Craft CMS 6. The deploy button in the dashboard deploys the latest commit. See the [deployment intro](/1.platform/06.deployment/01.intro.md) for how it works.

## Build commands

The [build command](/1.platform/06.deployment/03.build-commands.md) installs the Composer packages. Composer then publishes the Control Panel files to `public/vendor/craft`:

```shell
composer install --no-dev --prefer-dist --no-interaction --no-ansi --no-progress
```

Add `npm install` and `npm run build` for front-end assets built with Vite.

## Post-deploy commands

The [post-deploy commands](/1.platform/06.deployment/04.post-deploy-commands.md) run once the new code is live:

```shell
mkdir -p storage/framework/{sessions,views,cache}
php artisan migrate --force
php artisan storage:link --force
if php artisan craft:install:check; then php artisan craft:up; fi
if php artisan craft:install:check; then php artisan craft:clear-caches/all; fi
```

- `php artisan migrate` creates Laravel's tables, such as `cache` and `jobs`
- `php artisan storage:link` creates the `public/storage` link for [assets](/2.guides/3.craft-cms/40.craft-6/06.assets.md) again
- `php artisan craft:up` applies Craft's migrations and the project config from `config/craft/project/`
- `php artisan craft:clear-caches/all` clears Craft's caches. Without `/all`, it only lists them.
- `craft:install:check` skips both while Craft is not installed, so a deployment to an empty database passes

## Deployment strategy

Craft CMS 6 apps use the [replace strategy](/1.platform/06.deployment/08.strategy.md#replace-strategy) with an [exclude pattern](/1.platform/06.deployment/10.exclude-patterns.md) for `/storage`. A deployment deletes every file on the environment that is not in the repository, except in `storage`. Uploads on the `public` disk live there and survive a deployment.

The project config in `config/craft/project/` is not excluded, so the repository holds it. Make settings changes locally and commit them, as with Craft 5.

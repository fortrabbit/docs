## Git deployment

With the repository connected to the app, a `git push` to the deployment branch starts a deployment. The deploy button in the dashboard deploys the latest commit. See the [deployment intro](/1.platform/06.deployment/01.intro.md) for how it works.

## Settings from the template

Version 6 of the Craft CMS [software template](/1.platform/03.concepts/05.software-templates.md) sets the deployment:

:SoftwarePreset{slug="craft-cms" version="6"}

Change them in the deployment settings of the environment or with a [deploy file](/1.platform/06.deployment/06.deploy-file.md). Add `npm install` and `npm run build` to the build commands for front-end assets built with Vite.

## Notes

- `craft:install:check` skips `craft:up` while Craft is not installed, so the first deployment to an empty database passes.
- The [replace strategy](/1.platform/06.deployment/08.strategy.md#replace-strategy) deletes files that are not in the repository, except in `storage`. `storage:link` creates the `public/storage` link for [assets](/2.guides/3.craft-cms/40.craft-6/06.assets.md) again.
- The project config in `config/craft/project/` comes from the repository. Make settings changes locally and commit them.

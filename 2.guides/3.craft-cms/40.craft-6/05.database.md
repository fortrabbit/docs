## Database up

Craft CMS 6 on fortrabbit connects to the [MySQL database](/1.platform/09.components/02.mysql.md) through the `DB_*` [ENV vars](/2.guides/3.craft-cms/40.craft-6/04.env-vars.md). Export the local MySQL database, upload the dump and import it on fortrabbit:

- [Database up via terminal](/1.platform/08.mysql/02.export-import/08.database-up-terminal.md)
- [Database up via MySQL GUI](/1.platform/08.mysql/02.export-import/10.database-up-gui.md)

Deploy again after the import, so `php artisan craft:up` applies pending migrations and the project config.

## Database down

Download the database once editors work on the live site:

- [Database down via terminal](/1.platform/08.mysql/02.export-import/09.database-down-terminal.md)
- [Database down via MySQL GUI](/1.platform/08.mysql/02.export-import/11.database-down-gui.md)

A local PostgreSQL database does not import into MySQL. Develop with MySQL locally, see [install](/2.guides/3.craft-cms/40.craft-6/01.install.md).

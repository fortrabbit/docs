## Database connection

Craft CMS on fortrabbit connects to the [MySQL database](/1.platform/09.components/02.mysql.md) through the [ENV vars](/2.guides/3.craft-cms/07.env-vars.md) of the software template. After the first [deployment](/2.guides/3.craft-cms/03.deployment.md), the database is still empty: import the local database to bring content and structure up. The [MySQL export and import guides](/1.platform/08.mysql/02.export-import/07.intro.md) cover the terminal and GUI ways.

### Database up

1. Export the local database
2. Upload the dumped `.sql` file
3. Import the database dump into the app environment database

- [Database up via terminal](/1.platform/08.mysql/02.export-import/08.database-up-terminal.md)
- [Database up via MySQL GUI](/1.platform/08.mysql/02.export-import/10.database-up-gui.md)

### Database down

Download the database once editors work on the live site, to develop locally with current content.

1. Export the remote database
2. Download the dumped `.sql` file
3. Import the database in your local development

- [Database down via terminal](/1.platform/08.mysql/02.export-import/09.database-down-terminal.md)
- [Database down via MySQL GUI](/1.platform/08.mysql/02.export-import/11.database-down-gui.md)

## Install the fortrabbit GitHub App (recommended)

[Git deployment](/1.platform/06.deployment/01.intro.md) needs the [fortrabbit GitHub App](/1.platform/06.deployment/02.github-app.md) on the GitHub account. Check it in the account settings:

:BlockLink{title="Check GitHub app" path="/you/settings"}

Skip this step for an upload with SFTP or rsync.

## Create an app at fortrabbit

Create a new app in the dashboard, the wizard guides through the steps:

:BlockLink{title="Create a new app" path="/new/app"}

With the GitHub App installed, connect the repository now: fortrabbit detects Craft CMS from it. Without a repository, choose Craft CMS from the software list.

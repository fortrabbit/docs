## Headless Craft CMS

In headless mode, Craft CMS manages content and serves it through its [GraphQL API](https://craftcms.com/docs/5.x/development/graphql.html), without Twig templates. A separate frontend, built with Next, Nuxt, React or Vue, fetches the content and renders the pages. Craft runs on fortrabbit like any other Craft project; the frontend runs where its framework needs it, see [headless considerations](/3.dev/15.learn/05.headless.md).

## Compress JSON responses

fortrabbit compresses text responses such as `text/html`, `text/css` and `text/javascript`. The `application/json` responses of the GraphQL API are not compressed by default. Enable it in the `.htaccess` file, see [GZIP compression](/3.dev/21.htaccess/04.gzip.md).

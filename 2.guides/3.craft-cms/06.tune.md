## Logging

The software template sets `CRAFT_STREAM_LOG=true`. Craft then writes its logs to `stdout` and `stderr`, and they show up in the [logs](/1.platform/07.settings/25.logs.md) of the environment in the dashboard. Without that ENV var, Craft writes to `storage/logs/web.log`. See [Craft logging](https://craftcms.com/docs/5.x/system/logging.html).

## Sending mail

Send mail through a [transactional mail provider](/4.integrations/10.transactional-mail/01.intro.md). Pixel & Tonic, the makers of Craft, maintain a [Postmark plugin](https://plugins.craftcms.com/postmark). Also see the [limits on sending mail](/1.platform/03.concepts/09.limits.md).

## Redirects and HTTPS

Craft ships a `.htaccess` file in the `web` folder. Extend it with redirects or rules that force HTTPS, see the [.htaccess articles](/3.dev/21.htaccess/01.intro.md).

## Licensing

A Craft CMS license is tied to one domain. When the site moves from the test domain of the environment to its own domain, change the license domain in the [Craft Console](https://console.craftcms.com/).

## Storage folder

Plugins and crawlers can fill the `storage` folder: a faceted search plugin that caches a template fragment for every filter combination a bot requests, or a plugin with verbose logs. Check the size of the folder in the [storage](/1.platform/09.components/03.storage.md) metrics, and configure the plugin or block the crawler.

## Update locally first

Updates go into the [local development environment](/4.integrations/01.local-development/01.intro.md) first, get tested there, and reach fortrabbit with the next deployment. The [software template](/1.platform/03.concepts/05.software-templates.md) sets `CRAFT_ALLOW_UPDATES` and `CRAFT_ALLOW_ADMIN_CHANGES` to `false`, so the control panel on fortrabbit offers no updates.

Update Craft and all plugins locally in the control panel under **Utilities → Updates → Update all**, or in the terminal:

```shell
# List the available updates
php craft update

# Update Craft and all plugins
php craft update all
```

See the [Craft update docs](https://craftcms.com/docs/5.x/update.html) for single plugins and version constraints.

## Deploy the update

Commit `composer.json`, `composer.lock` and `config/project`, then `git push`. The [build commands](/1.platform/06.deployment/03.build-commands.md) run `composer install`, and the template sets these [post-deploy commands](/1.platform/06.deployment/04.post-deploy-commands.md):

```shell
php craft migrate/all
php craft project-config/apply
php craft clear-caches/all
```

They do nothing when no changes are pending. Change them in the deployment settings of the environment or in the [deploy file](/1.platform/06.deployment/06.deploy-file.md).

After an upload with [SFTP](/1.platform/05.code-access/04.sftp.md) or rsync, no post-deploy commands run. Apply migrations and project config over [SSH](/1.platform/05.code-access/03.ssh.md) with `php craft up`.

## Upgrade to a new major version

A major upgrade, such as Craft 4 to Craft 5, raises the requirements. Craft 5 needs PHP 8.2 or newer and starts from the latest Craft 4 release. A Craft 3 project goes to Craft 4 first, with the [Craft 4 upgrade guide](https://craftcms.com/docs/4.x/upgrade.html).

1. Follow the [Craft 5 upgrade guide](https://craftcms.com/docs/5.x/upgrade.html) locally, including the plugin updates and the **Craft 5 Upgrade** utility.
2. Set the environment to a PHP version Craft 5 supports, see [PHP version upgrade](/3.dev/20.how-to/upgrade-php.md).
3. Create a [backup](/1.platform/09.components/05.backups.md) of the environment.
4. Add the temporary `CRAFT_DB_CHARSET` and `CRAFT_DB_COLLATION` [ENV vars](/1.platform/07.settings/01.env-vars.md) the guide asks for, then deploy. The post-deploy commands run the migrations.
5. Remove the two ENV vars and run `php craft db/convert-charset` over SSH.

A plugin without a release for the new major version blocks the upgrade, see [Craft CMS plugins](/2.guides/3.craft-cms/14.plugins.md).

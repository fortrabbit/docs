## Get ready

- Have a [local development environment](/4.integrations/01.local-development/01.intro.md) running. [DDEV](/4.integrations/01.local-development/02.ddev.md) is recommended.
- Craft CMS 5 requires PHP 8.2 or newer, locally and on fortrabbit.
- Keep the [official Craft CMS install guide](https://craftcms.com/docs/5.x/install.html) at hand.
- Skip to [choose a deployment workflow](#choose-a-code-deployment-workflow) when a Craft project already runs locally.

## Install with Composer

Run this command **on the local machine** to create a new project. The setup wizard starts right after and asks for the database and the admin account:

```shell
composer create-project craftcms/craft my-project
```

With [DDEV](/4.integrations/01.local-development/02.ddev.md), prefix it: `ddev composer create-project craftcms/craft my-project`. To run the wizard again, for example after cloning an existing project, run `php craft setup` in the project folder.

Then build the site locally with templates, sections, fields, plugins and content.

## Choose a code deployment workflow

A Craft CMS project has three parts, and each one is deployed its own way:

- **Code**: Craft, plugins, templates and config, _decide now_
- [Database](/2.guides/3.craft-cms/04.database.md): content tables
- [Assets](/2.guides/3.craft-cms/05.assets.md): volumes with uploads

### A - Git deployment (recommended)

Put the project in a git repository on GitHub, here with the [GitHub CLI](/4.integrations/07.git-clients/02.gh-cli.md):

```bash
git init
git add .
git commit -m "Init"
gh repo create --private --source=. --push
```

Keep asset volumes out of git and [sync them separately](/2.guides/3.craft-cms/05.assets.md). Code already on GitHub? Skip this step. For other providers and CI pipelines see [Git provider integration](/4.integrations/03.git-providers/01.intro.md), for the basics the [deployment intro](/1.platform/06.deployment/01.intro.md) and the [Git intro](/3.dev/15.learn/git-intro.md).

### B - SFTP or rsync upload

Without git, upload the whole project folder, `vendor` included, with [SFTP](/1.platform/05.code-access/04.sftp.md) or [rsync](/3.dev/20.how-to/rsync.md). No build or post-deploy commands run then: run `composer install` locally before each upload and `php craft up` over [SSH](/1.platform/05.code-access/03.ssh.md) after it.

The package for Laravel Boost is on GitHub: [fortrabbit/laravel-boost](https://github.com/fortrabbit/laravel-boost).

## Add fortrabbit to Laravel Boost

```shell
composer require --dev laravel/boost fortrabbit/laravel-boost
php artisan boost:install
```

`boost:install` asks a few questions:

- Third-party packages: select `fortrabbit/laravel-boost`. It is not selected by default.
- Integrations: deselect Laravel Cloud. It is selected by default and adds the `deploying-to-cloud` skill.

Boost then writes a short fortrabbit guideline into `CLAUDE.md` or `AGENTS.md` and copies the [fortrabbit agent skill](/1.platform/04.automation/04.agent-skills.md) into each agent's skill folder, for example `.claude/skills/fortrabbit`. The skill is the same one the frbit CLI and the Claude Code plugin install. Commit the generated files, so everyone working on the repo gets them.

## Remove the Laravel Cloud line

Boost's own deployment guideline says Laravel Cloud is the fastest way to deploy. It stays in the guidelines even with the Cloud integration deselected. The fortrabbit guideline tells the agent to ignore it. To remove the line, publish the Boost config and exclude the guideline:

```shell
php artisan vendor:publish --tag=boost-config
```

```php
// config/boost.php
'guidelines' => [
    'exclude' => ['deployments'],
],
```

Then run `php artisan boost:update`. An own file at `.ai/guidelines/deployments/core.blade.php` replaces Boost's guideline too.

## Update

The package follows the releases of the agent skill:

```shell
composer update fortrabbit/laravel-boost
php artisan boost:update
```

## Connect the MCP server

Boost configures its own MCP server, not the fortrabbit one. The skill works over SSH without it. Connect the [MCP server](/1.platform/04.automation/02.mcp.md) to let the agent list environments, change environment variables and read deployment logs.

## MySQL configuration

Keep `config/database.php` as it is. The template fills `DB_HOST`, `DB_PASSWORD` and the other `DB_*` variables from the [MySQL component](/1.platform/09.components/02.mysql.md). Locally, the `.env` file holds the local credentials, see [ENV vars](/3.dev/19.env-vars/01.intro.md).

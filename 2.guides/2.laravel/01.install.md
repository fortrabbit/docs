## Get ready

Have a [local development environment](/4.integrations/01.local-development/01.intro.md) up and running.

## Install Laravel on your local machine

Follow the [Laravel installation guide](https://laravel.com/docs/installation). In short:

```shell
# Install the Laravel installer
composer global require laravel/installer

# Create a Laravel project
laravel new {project_folder_name}
```

Some software runs on top of Laravel, such as [Statamic](/2.guides/5.statamic/01.install.md), [Filament](/2.guides/2.laravel/06.filament.md) or [October CMS](/2.guides/7.more/06.october-cms.md).

## Develop locally

Build the app in the local environment. Hosting is needed once there is something to show.

## Set up GitHub

For Git deployment, put the code in a GitHub repository, public or private. With the [GitHub CLI](/4.integrations/07.git-clients/02.gh-cli.md):

```shell
# Setup local git repo
$ git init
$ git add -A
$ git commit -m 'Init'

# GitHub CLI to create/connect remote Git repo
$ gh repo new
# Follow the steps
# Push an existing local repository to github.com
# Add as remote and assign current branch as 'origin'
```

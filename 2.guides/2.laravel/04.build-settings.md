## Get ready

1. Have a [local development environment](/4.integrations/01.local-development/01.intro.md) running
2. Local [Laravel installation](/2.guides/2.laravel/01.install.md)
3. Know about [deployment features](/1.platform/06.deployment/01.intro.md)
4. Install the [fortrabbit GitHub app](/1.platform/06.deployment/02.github-app.md) with your GitHub account
5. Completed [Laravel setup steps](/2.guides/2.laravel/02.setup.md)
6. Ready for [Git deployment](/2.guides/2.laravel/03.deployment.md).

## Recommended Laravel build steps

The [stack detector](/1.platform/03.concepts/04.stack-detector.md) and the Laravel template set the [build commands](/1.platform/06.deployment/03.build-commands.md) for a repository from GitHub. Check them in the dashboard:

- Livewire and Inertia without server-side rendering work as they are. For Filament, see the [Filament guide](/2.guides/2.laravel/06.filament.md).
- Inertia with server-side rendering needs Node.js at runtime, which fortrabbit does not have: Node.js runs during the build only.

### Composer build step

The template runs Composer, see [Composer](/3.dev/15.learn/02.composer.md):

```shell
composer install --no-dev --prefer-dist --no-interaction --no-ansi --no-progress
```

### NPM build step

[Vite](https://vite.dev) bundles the assets of Laravel, see the [Laravel docs](https://laravel.com/docs/vite). With a `package.json` in the repository, the stack detector adds:

```shell
npm install
npm run build
```

The build writes to `public/build`, which `.gitignore` keeps out of the repository.

### Post-deploy commands

The template creates the storage folders Laravel needs and runs the migrations after each deployment:

```shell
mkdir -p storage/framework/{sessions,views,cache}
php artisan migrate --force
```

## Database and files

Git deploys the code only. Move the database with [MySQL export and import](/1.platform/08.mysql/02.export-import/07.intro.md), and uploads with [rsync](/3.dev/20.how-to/rsync.md), see [code moves up, content moves down](/1.platform/06.deployment/01.intro.md#code-moves-up-content-moves-down).

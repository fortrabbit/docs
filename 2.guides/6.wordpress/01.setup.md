Create an [app](/1.platform/10.objects/01.app.md) with WordPress as the software, then install WordPress in the [environment](/1.platform/10.objects/02.environment.md) over SSH. WordPress writes plugins, themes, updates and uploads into its own folders, which does not fit [Git deployment](/1.platform/06.deployment/01.intro.md) unless a setup such as [Bedrock](https://roots.io/bedrock/) separates code and content.

## Software template

WordPress carries no settings of its own, so an app running it deploys with the platform defaults:

:SoftwarePreset{slug="wordpress"}

## Install WordPress

Log in by SSH and download WordPress into the environment:

```shell
# 1. Login to your environment via SSH
$ ssh {{app-env-id}}@ssh.{{region}}.frbit.app

# Once you are logged in:

# 2. Download latest WordPress
$ wget https://wordpress.org/latest.tar.gz

# 3. Unpack wordpress
$ tar zxf latest.tar.gz

# 4. Move unpacked files to top level
$ mv wordpress/* .

# 5. Remove the downloaded container
$ rm -r wordpress latest.tar.gz
```

## Run the installer

Then open the default domain to run the installer:

:BlockLink{title="Visit default domain" path="https://{{app-env-id}}.{{region}}.frbit.app" property="none"}

The installer asks for the database credentials, which the MySQL settings of the environment in the dashboard show, then for the site title and the admin account. It ends at the login of wp-admin.

## Installing themes and plugins

Install themes and plugins in wp-admin, or upload custom ones to `wp-content` by [SFTP](/1.platform/05.code-access/04.sftp.md) or [rsync](/3.dev/20.how-to/rsync.md).

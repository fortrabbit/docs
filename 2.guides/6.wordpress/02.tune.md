### Changing the site_url domain in the wp-admin

In wp-admin under Settings > General, set "WordPress Address (URL)" and "Site Address (URL)" to the new domain. Links stored in the content still point to the old address: replace them with `wp search-replace` (below), see [moving WordPress](https://developer.wordpress.org/advanced-administration/upgrade/migrating/).

## Database migration

Most WordPress content lives in the [MySQL database](/1.platform/09.components/02.mysql.md). Move it from the old host, up from local, or down from fortrabbit with [export and import](/1.platform/08.mysql/02.export-import/07.intro.md).

## Deploying WordPress changes with rsync

[rsync](/3.dev/20.how-to/rsync.md) uploads only what changed, for example a theme folder, and is faster than SFTP.

## Using the WP-CLI

[WP-CLI](https://wp-cli.org) is installed on every environment. Run it over [SSH](/1.platform/05.code-access/03.ssh.md) in the WordPress folder:

```shell
$ wp core version
$ wp plugin update --all
$ wp search-replace 'https://old.example.com' 'https://www.example.com'
```

See the [WP-CLI commands](https://developer.wordpress.org/cli/commands).

## Image sizes

WordPress creates every registered image size during the upload request. Themes and plugins add sizes, so one upload can mean many resized copies. Photos larger than the [big image threshold](https://developer.wordpress.org/reference/hooks/big_image_size_threshold/) of 2560 pixels are scaled down first. Keep the list of sizes short and uploads small.

WordPress has no queue of its own to move this to a background [worker](/1.platform/30.jobs/03.workers.md). The [Image Processing Queue](https://wordpress.org/plugins/image-processing-queue/) plugin creates the image sizes a theme requests through it in the background. We have not tested it, and its last release dates from 2017. See [image transforms](/3.dev/02.performance/12.image-transforms.md).

## Running WordPress in a sub folder

For a blog under `example.com/blog`, install WordPress in a folder and set the "Site Address (URL)" accordingly, see [give WordPress its own directory](https://developer.wordpress.org/advanced-administration/server/wordpress-in-directory/). For several WordPress sites, use one environment or app each, not folders in one environment.

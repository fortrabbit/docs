## Get ready

- A [local development environment](/4.integrations/01.local-development/01.intro.md) with [Kirby installed](/2.guides/4.kirby/01.install.md)
- An app on fortrabbit, created with the Kirby software

## Deployment

Sync the project folder up and down:

```shell
# UP: from local to remote (syncs to the app root)
$ rsync -av ./ {{app-env-id}}@ssh.{{region}}.frbit.app:

# DOWN: from remote to local (syncs from the app root)
$ rsync -av {{app-env-id}}@ssh.{{region}}.frbit.app: ./
```

See the [rsync article](/3.dev/20.how-to/rsync.md) for more details.

## The vendor folder

rsync uploads the local `vendor` folder too. Keep the local PHP version close to the [PHP version](/1.platform/07.settings/06.php.md) of the environment. Alternatively, run `composer install` over SSH, or switch to [Git and rsync](/2.guides/4.kirby/03.git-and-rsync.md), where the build commands install the dependencies.

## Choose a deployment workflow

- [Git and rsync](/2.guides/4.kirby/03.git-and-rsync.md): code by Git, content by rsync. Recommended.
- [rsync only](/2.guides/4.kirby/04.rsync.md): everything by rsync, quick for small sites.
- [SFTP](/1.platform/05.code-access/04.sftp.md): uploads by hand.
- Git only: content in Git too, when nobody edits in the panel on the server.

## Get ready

A [local development environment](/4.integrations/01.local-development/01.intro.md) with PHP 8.5 and Composer. Set the [PHP version](/1.platform/07.settings/06.php.md) of the environment to 8.5 too.

## Install Tempest locally

See the [Tempest installation guide](https://tempestphp.com/3.x/getting-started/installation). A new project:

```shell
composer create-project tempest/app my-app
cd my-app
```

## Set up GitHub

For [Git deployment](/1.platform/06.deployment/01.intro.md), push the project to a GitHub repository, for example with the [GitHub CLI](/4.integrations/07.git-clients/02.gh-cli.md):

```shell
# Setup local git repo
$ git init
$ git add -A
$ git commit -m 'Init'

# GitHub CLI to create/connect remote Git repo
$ gh repo new
# Follow the steps
# Push an existing local repository to github.com
# Add as remote and assign current branch as 'origin'
```

[rsync](/3.dev/20.how-to/rsync.md) over SSH works as well.

## Create an app at fortrabbit

Create an app with Tempest as the software and connect the GitHub repository.

:BlockLink{title="Create a new app" path="/new/app"}

The [software template](/1.platform/03.concepts/05.software-templates.md) sets the root path `public` and the database ENV vars.

## Create signing key

Tempest signs some data with a key. Create it over SSH, or set the `SIGNING_KEY` ENV var:

```shell
# Login by SSH
$ ssh {{app-env-id}}@ssh.{{region}}.frbit.app

# Create the signing key
php tempest key:generate
```

## ENV vars

Tempest reads its configuration from ENV vars. With MySQL, set these in the [ENV vars](/1.platform/07.settings/01.env-vars.md):

```shell
DATABASE_HOST=${FORTRABBIT_DB_HOST}
DATABASE_DATABASE=${FORTRABBIT_DB_NAME}
DATABASE_USERNAME=${FORTRABBIT_DB_USER}
DATABASE_PASSWORD=${FORTRABBIT_DB_PASSWORD}
DATABASE_PORT=${FORTRABBIT_DB_PORT}
```

:BlockLink{title="Edit ENV vars for {{app-name}} / {{app-env-name}}" path="/environments/{{app-env-id}}/env-vars/edit"}

## Database configuration

Tempest uses SQLite by default. For MySQL, create `app/Config/database.config.php`:

```php
use Tempest\Database\Config\MysqlConfig;

return new MysqlConfig(
    host: env('DATABASE_HOST', '127.0.0.1'),
    port: (int) env('DATABASE_PORT', 3306),
    username: env('DATABASE_USERNAME'),
    password: env('DATABASE_PASSWORD'),
    database: env('DATABASE_DATABASE'),
);
```

Run migrations by hand over SSH:

```shell
ssh {{app-env-id}}@ssh.{{region}}.frbit.app 'php tempest migrate:up'
```

## Deployment configuration

Set these in the deployment settings:

```shell
# Build commands
## Install by composer
composer install --no-dev --prefer-dist --no-interaction --no-ansi --no-progress

# Post deploy commands
##  Run database migrations (with MySQL enabled)
php tempest migrate:up
```

With a `package.json`, add `npm install` and `npm run build` to the build commands. See the [Tempest deployment docs](https://tempestphp.com/3.x/extra-topics/deployments) for more commands, such as discovery caching.

## Get ready

Install October CMS in a [local development environment](/4.integrations/01.local-development/01.intro.md), see the [October install guide](https://docs.octobercms.com/3.x/setup/installation.html). October runs on Laravel, so the [Laravel guides](/2.guides/2.laravel/01.install.md) apply too.

### MySQL configuration

The October [software template](/1.platform/03.concepts/05.software-templates.md) sets the `DB_*` ENV vars, so `config/database.php` stays as it is. Locally, the `.env` file holds the local credentials, see [ENV vars](/3.dev/19.env-vars/01.intro.md).

### Public folder

The template sets the [root path](/1.platform/07.settings/12.root-path.md) to `public`. October creates that folder with `php artisan october:mirror`, and needs it again after updates and new plugins. Add the command as a [post deploy command](/1.platform/06.deployment/04.post-deploy-commands.md), see [October web server configuration](https://docs.octobercms.com/3.x/setup/web-server-config.html).

## User sessions

Set the session driver with the `SESSION_DRIVER` ENV var, see the [Laravel session docs](https://laravel.com/docs/session#configuration). The storage is persistent, so the `file` driver works. For the `database` driver:

```shell
# Create a migration for the session table  - locally
$ php artisan session:table

# Apply the migration - locally
$ php artisan migrate

# Add, commit and push the migration file
$ git add .
$ git commit -m "session migration"
$ git push

# Run the migration on the App via SSH remote execution
$ ssh {{app-env-id}}@ssh.{{region}}.frbit.app php artisan migrate --force
```

## Sending mail

fortrabbit has no [sendmail](/1.platform/03.concepts/09.limits.md#mailing). October sends through Laravel mail: set the SMTP host, port, credentials and from address in `config/mail.php` or the mail settings of the backend, with a mail account or a [transactional mail provider](/4.integrations/10.transactional-mail/01.intro.md).

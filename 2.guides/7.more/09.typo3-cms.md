## Get ready

Create an app with TYPO3 as the software, so the [software template](/1.platform/03.concepts/05.software-templates.md) applies. It covers TYPO3 12 to 14. Install TYPO3 in a [local development environment](/4.integrations/01.local-development/01.intro.md) first, see the [TYPO3 installation guide](https://docs.typo3.org/m/typo3/reference-coreapi/main/en-us/Administration/Installation/Index.html), for example with [Composer](/3.dev/15.learn/02.composer.md):

```shell
composer create-project typo3/cms-base-distribution example-project-directory "^13"
```

## Root path

The template sets the [root path](/1.platform/07.settings/12.root-path.md) to `public`.

:BlockLink{title="Change the root path for {{app-name}} / {{app-env-name}}" path="/environments/{{app-env-id}}/settings/rootpath"}

## MySQL

TYPO3 does not read the database settings from ENV vars on its own, and the template sets none. Two options:

- Read the [platform database variables](/1.platform/08.mysql/01.access/04.access-environment.md), `FORTRABBIT_DB_HOST` and the others, in `config/system/additional.php`. This works with Git deployment.
- Run the TYPO3 installer on the environment, which writes the settings into `config/system/settings.php`.

## Deployment

Deploy with Git through the [GitHub App](/1.platform/06.deployment/02.github-app.md); the build commands run Composer. The template uses the [merge strategy](/1.platform/06.deployment/08.strategy.md), so files TYPO3 writes, such as `fileadmin` and `config/system/settings.php`, stay across deployments. SSH and SFTP work too.
